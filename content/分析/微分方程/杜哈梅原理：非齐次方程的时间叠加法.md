**【核心 Takeaway】**

>面对非齐次演化方程，源项 $f(x,t)$ 并不是持续存在的负担。杜哈梅原理的精髓在于：将外力视为每一极短瞬间施加的“冲量”，把非齐次方程转化为无数个齐次方程“初速度”的线性叠加。

### The Setup 

对于经典的非齐次波动方程：

$$\left\{\begin{array}{l} \frac{\partial^2 u}{\partial t^2}-a^2 \frac{\partial^2 u}{\partial x^2}=f(x, t) \\ u|_{t=0}=0, \left.\frac{\partial u}{\partial t}\right|_{t=0}=0 \end{array}\right.$$

面对等式右边复杂的非齐次项 $f(x, t)$，如果我们纯粹从代数角度去寻找特解往往十分繁琐。但如果切换到物理视角，答案其实就隐藏在方程本身之中。

### 物理直觉

根据物理学，$f(x,t)$ 的物理意义是：**在 $t$ 时刻、$x$ 位置，单位质量受到的外力**。

**物理想法：**

根据方程的叠加性质, 我们在任意时刻 $\tau$，在极小时间范围 $\Delta \tau$ 内考虑这个力的作用。由于作用时间极短，系统来不及发生位移，**仅仅改变了初始的速度**。在这之后，外力相当于撤去，系统仍然进行**齐次演化**，我们将此时的局部波函数记为 $W(x,t,\tau)$。

根据动量定理，$f(x,\tau)\Delta \tau$ 代表了受力转化而来的速度增量，即辅助方程的初始条件变为：

$$\left\{\begin{array}{l} \frac{\partial^{2}W}{\partial t^{2}} -a^{2}\frac{\partial^{2}W}{\partial x^{2}} =0 \\ W|_{t=\tau}=0, \left.\frac{\partial W}{\partial t}\right|_{t=\tau} =f(x,\tau)\Delta \tau \end{array}\right.$$

由于波函数满足线性叠加原理，把每一个时间切片 $\tau$ 产生的 $W_i$ 求和，就能得到整体响应：$u = \lim_{\lambda(P)\to0} \sum W_{i}$。

但是，这里的 $W_{i}$ 包含的初速度是一个无穷小量，为了符合教科书中通用函数的定义，我们提取出一个辅助函数 $W_{i}' = \frac{W_{i}}{\Delta \tau}$。也就是说，直接把初值取为 $f(x,\tau)$：

$$\left\{\begin{array}{l} \frac{\partial^2 W'}{\partial t^2}-a^2 \frac{\partial^2 W'}{\partial x^2}=0 \quad(t>\tau) \\ W'|_{t=\tau}=0, \left.\frac{\partial W'}{\partial t}\right|_{t=\tau}=f(x, \tau) \end{array}\right.$$

这样一来，离散的求和就顺理成章地化为了积分：

$$u(x, t)=\lim_{\lambda(P)\to0} \sum W_{i}'\Delta \tau = \int_{0}^{t} W'(x,t,\tau) \, d\tau$$

为了方便计算，通常令 $t'=t-\tau$，使演化时间从 0 开始，代入常规的达朗贝尔公式即可解得 $u(x,t)$。

### 一般情况的推导

一般地，对于包含任意空间算子 $L$ 的高阶演化方程 $\frac{\partial^k u}{\partial t^k} + Lu = f(x,t)$，我们同样可以构造齐次辅助方程（初值仅在 $k-1$ 阶导数为 $f(x,\tau)$）：

$$\left\{\begin{array}{l} \frac{\partial^k W}{\partial t^k} - L W = 0 \quad (t > \tau)\\ W|_{t=\tau} = \cdots = 0, \quad \left.\frac{\partial^{k-1} W}{\partial t^{k-1}}\right|_{t=\tau} = f(x,\tau) \end{array}\right.$$

断言其解同样为 $u(x,t) = \int_0^t W(x, t; \tau) d\tau$。

**极简验证：**

利用 Leibniz 变上限积分求导法则对 $u(x,t)$ 逐次求时间导数。在前 $k-1$ 次求导时，由于 $W$ 及其低阶导数在 $t=\tau$ 时初值皆为 0，变上限代入项（即在积分上限处求值的那一项）全为 0：

$$\frac{\partial^{j} u}{\partial t^{j}} = \int_0^t \frac{\partial^{j} W}{\partial t^{j}} d\tau \quad (j \le k-1)$$

唯独当求第 $k$ 阶导数时，变上限代入项恰好“释放”出了初始条件 $f(x,t)$：

$$\frac{\partial^k u}{\partial t^k} = f(x,t) + \int_0^t \frac{\partial^k W}{\partial t^k} d\tau = f(x,t) + L\int_0^t W d\tau = f(x,t) + Lu$$

移项即得 $\frac{\partial^k u}{\partial t^k} - Lu = f(x,t)$，原方程直接得证。

### 时间平移不变性

在实际计算中，由于空间微分算子 $L$ 不显含时间 $t$（系统时齐），系统具有**时间平移不变性**：在 $t=\tau$ 时刻给予系统的冲击，其演化规律与 $t=0$ 时完全相同，仅在时间轴上向后平移了 $\tau$ 个单位。

因此，实际计算时, 只需要：

1. **解 $t=0$ 的标准初值问题**：直接求解初值为 $f(x, \tau)$ 的标准齐次方程，得到解 $W(x, t)$。
2. **时间平移**：将解中的 $t$ 直接替换为 $t-\tau$. 代入总积分，写出最终答案：
$$u(x,t) = \int_0^t W(x, t - \tau) \, d\tau$$
**一维波动方程实例：**

标准齐次解为 $\frac{1}{2a} \int_{x-at}^{x+at} f(\xi, \tau) \mathrm{d}\xi$，完成平移并积分：

$$u(x, t) = \frac{1}{2a} \int_0^t \int_{x-a(t-\tau)}^{x+a(t-\tau)} f(\xi, \tau) \mathrm{d} \xi \mathrm{~d} \tau$$
