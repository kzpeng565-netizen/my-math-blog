## 一、 初等积分法（解微分方程）

这是纯粹的计算基本功，考试中通常以填空题或第一道计算题的形式出现。

**核心知识点**

- **变量分离方程：** 形如 $y' = f(x)g(y)$。
    
- **齐次方程：** 形如 $y' = f(\frac{y}{x})$，通过代换 $u = \frac{y}{x}$ 转化为变量分离。
    
- **一阶线性方程：** 形如 $y' + P(x)y = Q(x)$，使用常数变易法或积分因子公式。
    
- **恰当方程（全微分方程）：** 形如 $M(x,y)dx + N(x,y)dy = 0$，满足 $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$。
    
- **积分因子：** 寻找 $\mu(x,y)$ 使得 $\mu M dx + \mu N dy = 0$ 成为恰当方程。
    
- **可降阶的高阶方程：** 缺 $y$ 型 $F(x, y', y'') = 0$ 或缺 $x$ 型 $F(y, y', y'') = 0$。
    

**常考题型与技巧**

- **题型：** 直接求解初值问题 (IVP) 或通解。
    
- **技巧（识别类型）：** 拿到题目先看能不能变量分离；不行看齐次；再看是不是线性；如果是 $Mdx+Ndy=0$ 形式，立刻验证交叉偏导数。
    
- **技巧（分组凑微分）：** 熟记常见的全微分形式，例如 $d(xy) = xdy + ydx$，$d(\frac{y}{x}) = \frac{xdy - ydx}{x^2}$ 等，可以秒杀很多看似复杂的积分因子题。

## 二、 解的适定性理论

这是常微分方程的理论基石，通常出证明题或概念辨析题。

**核心知识点**

- **Picard 存在唯一性定理：** 局部Lipschitz条件是核心。若 $f(t,x)$ 在矩形区域内连续，且对 $x$ 满足Lipschitz条件，则初值问题存在唯一局部解。
    
- **Peano 存在性定理：** 仅需连续性，就能保证解的存在性（但不保证唯一）。
    
- **解的延拓：** 极大存在区间，解如何逼近区域的边界（逃逸到无穷或到达定义域边界）。
    
- **解对初值和参数的连续依赖性/可微性：** 证明解的稳定性。
    
- **Picard 逐步逼近法：** 迭代构造序列 $x_{n+1}(t) = x_0 + \int_{t_0}^t f(s, x_n(s)) ds$。
    

**常考题型与技巧**

- **题型：** 判断某方程是否存在唯一解；求逐步逼近序列的前几项；证明解的连续依赖性。
    
- **技巧（验证 Lipschitz 条件）：** 最常用的方法是求偏导 $\frac{\partial f}{\partial x}$。如果偏导数在闭区域内连续（有界），则必然满足 Lipschitz 条件。注意区分**局部 Lipschitz** 和**全局 Lipschitz**。
    
- **技巧（反例构造）：** 遇到 $y' = y^{\alpha}$（$0 < \alpha < 1$），在 $y=0$ 处不满足 Lipschitz 条件，通常用于说明不唯一性（例如 $y' = \sqrt{y}, y(0)=0$ 有两个解：$y=0$ 和 $y = \frac{x^2}{4}$）。

## 三、 线性微分方程的一般理论 & 朗斯基行列式

这一部分是线性代数与微积分的完美结合，理论性较强。

**核心知识点**

- **叠加原理：** 齐次方程解的线性组合仍是解；非齐次通解 = 齐次通解 + 非齐次特解。
    
- **线性相关与线性无关：** 函数组线性无关的定义。
    
- **朗斯基行列式 (Wronskian)：** $W(t) = \det[y_1, y_2, \dots, y_n]$。对于线性微分方程的解，$W(t)$ 要么恒为零，要么恒不为零。
    
- **刘维尔-阿贝尔 (Liouville-Abel) 公式：** $W(t) = W(t_0) \exp(-\int_{t_0}^t a_{n-1}(s) ds)$。
    

**常考题型与技巧**

- **题型：** 给定几个函数，判断是否能作为某个线性微分方程的基础解系；利用已知特解求通解（降阶法）。
    
- **技巧（Abel 公式的妙用）：** 已知二阶线性方程的一个解 $y_1$，求另一个解 $y_2$。不需要死记降阶公式，直接利用 $W(t) = y_1 y_2' - y_1' y_2 = C \exp(-\int p(x)dx)$ 构造一阶线性方程求解，速度快且不易算错。

## 四、 线性方程组与基解矩阵

这是高维空间中的线性理论，主要围绕矩阵指数展开。

**核心知识点**

- **一阶线性方程组：** $\dot{x} = A(t)x$。
    
- **基解矩阵 $\Phi(t)$：** 列向量为线性无关的解。满足 $\dot{\Phi} = A(t)\Phi$。
    
- **常系数系统与矩阵指数：** 当 $A$ 为常数矩阵时，标准基解矩阵为 $e^{At}$。
    
- **通解公式（常数变易法）：** $x(t) = e^{A(t-t_0)}x_0 + \int_{t_0}^t e^{A(t-s)}b(s)ds$。
    

**常考题型与技巧**

- **题型：** 计算 $e^{At}$；求解 $\dot{x} = Ax + b(t)$。
    
- **技巧（计算 $e^{At}$ 的三种武器）：**
    
    1. **特征值法（最常用）：** 寻找特征向量和广义特征向量构造解。
        
    2. **化零多项式/凯莱-哈密顿定理：** 若 $A^2 = 0$ 或有简单规律，直接通过泰勒级数展开 $e^{At} = I + At + \frac{A^2t^2}{2!} + \dots$ 截断。
        
    3. **拉普拉斯变换：** $e^{At} = \mathcal{L}^{-1} \{ (sI - A)^{-1} \}$，适合特征值带有理数，手算矩阵求逆方便的情况。

## 五、 Gronwall 不等式 & Bootstrap 方法

这是现代偏微分方程和常微分方程高级分析中的核心工具，用于“先验估计 (A Priori Estimates)”。

**核心知识点**

- **Gronwall 不等式（积分形式）：** 若 $u(t) \le a + \int_{t_0}^t b(s)u(s) ds$（其中 $b(s) \ge 0$），则 $u(t) \le a \exp(\int_{t_0}^t b(s)ds)$。
    
- **Gronwall 不等式（微分形式）：** 若 $u'(t) \le \beta(t) u(t)$，则 $u(t) \le u(t_0)\exp(\int_{t_0}^t \beta(s)ds)$。
    
- **Bootstrap 方法（连续归纳法）：** 用于证明局部解可以全局存在，或者证明解的某种界限始终成立。其逻辑链条通常为：假设在时间 $T$ 内某个界限成立 $\implies$ 利用方程结构推导出一个更严格的界限 $\implies$ 通过连续性证明这个界限在更长的时间内也成立，从而突破限制。
    

**常考题型与技巧**

- **题型：** 证明解的唯一性（常常通过证明两个解的差 $w = x_1 - x_2$ 满足 $w \le \int C w ds$，从而由 Gronwall 得出 $w \le 0$）；证明解的全局有界性。
    
- **技巧（构造放缩）：** 在使用 Gronwall 时，关键是把不等式凑成 $u \le a + \int b u$ 的形式。遇到非线性的常数或积分，果断使用三角不等式、柯西不等式 (Cauchy-Schwarz) 或杨氏不等式 (Young's Inequality) 进行放缩，把非线性项压制到线性的 Gronwall 框架内。

## 六、 首次积分 (First Integrals)

常用于求解高阶方程组或对称形式的方程组，是分析力学中的重要概念。

**核心知识点**

- **对称形式的方程组：** $\frac{dx_1}{X_1} = \frac{dx_2}{X_2} = \dots = \frac{dx_n}{X_n}$。
    
- **首次积分的定义：** 沿着方程的解轨线保持不变的非常数函数 $\Phi(x_1, x_2, \dots, x_n) = C$。
    
- **完全积分：** 找到 $n-1$ 个函数独立的首次积分，就能隐式地给出积分曲线（通解）。
    

**常考题型与技巧**

- **题型：** 给定对称型方程组，求其首次积分或通解。
    
- **技巧（等比定理合分比法）：** 看到 $\frac{dx}{P} = \frac{dy}{Q} = \frac{dz}{R}$，最强大的武器是寻找乘子 $l, m, n$，使得：
    
    $$\frac{dx}{P} = \frac{dy}{Q} = \frac{dz}{R} = \frac{ldx + mdy + ndz}{lP + mQ + nR}$$
    
    巧妙选择 $l, m, n$ 使得分母 $lP + mQ + nR = 0$，从而立刻得到分子 $ldx + mdy + ndz = 0$，直接积分即可得到一个首次积分。
