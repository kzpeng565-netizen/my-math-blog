# 1. 局部双射的充要条件

>[!1]
> A holomorphic mapping $f: U \rightarrow V$ is a local bijection on $U$ if for every $z \in U$ there exists an open disc $D \subset U$ centered at $z$, so that $f: D \rightarrow f(D)$ is a bijection.
> 
> Prove that a holomorphic map $f: U \rightarrow V$ is a local bijection on $U$ if and only if $f^{\prime}(z) \neq 0$ for all $z \in U$.
> [Hint: Use Rouché's theorem as in the proof of Proposition 1.1.]

- Sufficiency
We assume $f'(z)\neq0$, proving $f$ is local bijective.
Since $f'(z)\neq0$, zero of $f(z)-w$ is always simple root.
we just need to prove that, for every $z_{0}\in U$, there is a neighborhood $U_{r}(z_{0})$ such that $f:U_{r}(z_{0})\to f(U_{r}(z_{0}))$ is bijective.
Let $w_{0}=f(z_{0})$. By isolated zero property, we can find $U_{R}(z_{0})$ such that $f(z)-w_{0}$ has only one zero.
So, for any $w,$which satisfies $\left| w-w_{0} \right|<\inf_{z\in C_{R}(z_{0})}\left| f(z)-w_{0} \right|:=K$, we have $f-w$ has only one zero.
Hence, if we find $U_{r}(z_{0}),r\leq R,f(U_{r}(z_{0}))\subset U_{K}(w_{0})$, there are only one zero for $f(z)-w,z\in U_{r}(z_{0})$ with $w\in f(U_{r}(z_{0}))$. Thus, $f$ is injective.
$\forall w\in f(U_{r}(z_{0})),\left| w-w_{0} \right|=\left| f(z)-w_{0} \right| =\left| z-z_{0} \right|\left| g(z) \right|\leq \left| z-z_{0} \right|\sup_{z\in D_{R}(z_{0})}\left| g(z) \right|$. Therefore, we make $r= \frac{1}{2} \frac{K}{\sup_{z\in D_{R}(z_{0})}\left| g(z) \right|}$ and it follows that $\left| w-w_{0} \right|<K,\forall w=f(z),z\in U_{r}(z_{0})$. Then, we have $f:U_{r}(z_{0})\to f(U_{r}(z_{0}))$ is one-to-one and obviously onto.

- Necessary
[[复分析11 Conformal map]] gives a theorem: if $f:U\to V$ is conformal, then $f'\neq0$ for all $z\in U$.
By local bijection, for all $z\in U$, $\exists U_{r}(z)$, s.t. $f:U_{r}(z)\to f(U_{r}(z))$ is conformal, then $f'(z)\neq0$ for any $z\in U_{r}(z)$. This completes the proof.

# 3. 共形等价与单连通性

>[!3]
> Suppose $U$ and $V$ are conformally equivalent. Prove that if $U$ is simply connected, then so is $V$. Note that this conclusion remains valid if we merely assume that there exists a continuous bijection between $U$ and $V$.

Let $\pi:U\to V$ is a continuous bijection between U and V. Let $\gamma_{1},\gamma_{0}:[0,1]\to V$ is two continuous curves that share their end points. Noting that $\gamma'_{1}=\pi ^{-1}(\gamma_{1}),\gamma'_{0}=\pi ^{-1}(\gamma_{0})$ are continuous curves in U and share their endpoints, we have $H:[0,1]\times[0,1]\to U$ are homotopic map that $H(0,t)=\gamma_{0}'(t),H(1,t)=\gamma_{1}'(t)$ 
Then $\pi(H(0,t))=\gamma_{0},\pi(H(1,t))=\gamma_{1}$ and $\pi \circ H$ is continuous. 

# 5. 特定共形映射

>[!5]
> Prove that $f(z)=-\frac{1}{2}(z+1 / z)$ is a conformal map from the half-disc $\{z=x+i y:|z|<1, y>0\}$ to the upper half-plane.
> [Hint: The equation $f(z)=w$ reduces to the quadratic equation $z^2+2 w z+1=0$, which has two distinct roots in $\mathbb{C}$ whenever $w \neq \pm 1$. This is certainly the case if $w \in \mathbb{H}$.]

1. $f(U)\subset V$, $U$ is half-disc, and $V$ is half-plane
$\iff \mathrm{Im}\left( -z-\frac{1}{z} \right)>0\iff x^{2}y+y^{3}-y<0\iff x^{2}+y^{2}<1$ 

2. f is injective
$-\frac{1}{2}\left( z+\frac{1}{z} \right)=w\implies z^{2}+2wz+1=0\implies z_{1}+z_{2}=-2w,z_{1}z_{2}=1$. Hence, if$f(z_{1})=w$, it gvies that $\left| z_{2} \right|>1$, which means, there is only one root in $U$

3. f is surjective
Since $w\neq\pm1,$there are two roots in $\mathbb{C}$. We prove one of them lying in U.
We know that one root $z$ satisfies $\left| z \right|<1$
$z=x+iy,w=a+bi$, $\mathrm{Im}-\frac{1}{2}\left( x+iy+ \frac{1}{x+iy} \right)= -\frac{1}{2}\frac{x^{2}y+y^{3}-y}{x^{2}+y^{2}}= -\frac{1}{2}\frac{ry-y}{r}>0$
So $z=f^{-1}(w)$

## 例2 
$f(z)$在$z_{0}$处全纯, $w_{0}=f(z_{0})$, 若$f(z)$在$z_{0}$处取值$w_{0}$ k次, ($f(z)-w_{0}$​	在$z_{0}$处有k阶零点)
证明：存在 $r>0$ 与 $\delta>0$，使得对于任意 $w \in D^*(w_0, \delta)$，方程 $f(z) = w$ 在去心邻域 $D^*(z_0, r)$ 内恰好有 $k$ 个不同的解。

Proof.
There is a neighborhodd of $z_{0}$ such that $f(z)\neq0,f'(z)\neq0$ for all $z\in D_{r}(z_{0})$ , and $min_{\left| z-z_{0} \right|=r}\left| f(z)-w_{0} \right|:=\delta$
when $w\in D^{*}(w_{0},\delta)$, we have $\left| f(z)-w-(f(z)-w_{0}) \right|=\left| w-w_{0} \right|<\delta$ i.e. $\left| w-w_{0} \right|<\left| f(z)-w_{0} \right|$ holds
Hence$f(z)-w$ zeros in $D_{\delta}(z_{0})$ for k times and without multiple zero.

## 茹科夫斯基函数

$f(z)=- \frac{1}{2}\left( z+\frac{1}{z} \right)$​	 
当$\left| z \right|=r_{0}$, $$f(z)=- \frac{1}{2}\left( r_{0}e^{i\theta}+\frac{1}{r_{0}}e^{=i\theta} \right)= -\frac{1}{2}\left[ r_{0}(\cos\theta+i\sin\theta)+\frac{1}{r_{0}}(\cos\theta-i\sin\theta) \right]=-\frac{1}{2}\left[ \left( r_{0}+\frac{1}{r_{0}} \right)\cos\theta+i\left( r_{0}-\frac{1}{r_{0}} \right)\sin\theta \right]$$
$\left( \frac{u}{r_{0}+\frac{1}{r_{0}}} \right)^{2}+\left( \frac{v}{r_{0}-\frac{1}{r_{0}}} \right)^{2}=1$ 椭圆的焦点是1

$\implies \left( \frac{u}{\cos\theta_{0}} \right)^{2}-\left( \frac{v}{\sin\theta_{0}} \right)^{2}=1$
