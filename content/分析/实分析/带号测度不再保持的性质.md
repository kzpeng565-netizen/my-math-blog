构造反例是实变函数学习中最核心的能力之一，这说明你正在经历从“记忆定理”到“理解定理边界”的蜕变，这种思维对你未来在数学所的研究会非常有帮助。

为了让反例尽可能直观，我们都在实数集 $\mathbb{R}$ 上，利用你最熟悉的 Lebesgue 测度 $\lambda$ 结合密度函数来构造带号测度。设带号测度定义为 $d\nu = f dx$（即 $\nu(A) = \int_A f(x) dx$）。

### 1. 次可加性（Boole 不等式）失效的反例

**定理回顾**：对于正测度，$\mu(A \cup B) \le \mu(A) + \mu(B)$ 始终成立。

**失效原因**：带号测度中，集合重叠部分如果含有负测度，会使得单独相加时的“负贡献”被重复计算，从而导致等式右边变得更小。

**反例构造**：

在 $[0, 2]$ 上定义带号测度 $\nu$，其密度函数为：

$$f(x) = \begin{cases} 1, & x \in [0, 1] \\ -1, & x \in (1, 2] \end{cases}$$

我们选取两个有重叠的集合：

- $A = [0, 2]$
    
- $B = (1, 2]$
    

**验证**：

首先，计算并集的测度。因为 $A \cup B = [0, 2]$：

$$\nu(A \cup B) = \nu([0, 2]) = \int_0^1 1 dx + \int_1^2 (-1) dx = 1 - 1 = 0$$

然后，分别计算两者的测度并相加：

$$\nu(A) = 0$$

$$\nu(B) = \int_1^2 (-1) dx = -1$$

所以 $\nu(A) + \nu(B) = 0 + (-1) = -1$。

**结论**：

此时 $0 \not\le -1$，即 $\nu(A \cup B) > \nu(A) + \nu(B)$，次可加性失效。

### 2. 积分极限定理（如 Fatou 引理）失效的反例

**定理回顾**：对于正测度 $\mu$ 和非负可测函数列 $f_n \ge 0$，Fatou 引理保证了 $\int \liminf_{n \to \infty} f_n d\mu \le \liminf_{n \to \infty} \int f_n d\mu$。

**失效原因**：Fatou 引理的本质依赖于积分的单调性，而当测度取负值时，非负函数乘上负的测度权重，不等号的方向会被完全颠倒。

**反例构造**：

考虑 $[0, 1]$ 上的带号测度 $\nu = -\lambda$（即纯粹的负 Lebesgue 测度，$d\nu = -dx$）。

构造经典的“变窄变高的脉冲函数列”：

$$f_n(x) = n \cdot \chi_{(0, \frac{1}{n})}(x)$$

**验证**：

显然对于所有的 $n$ 和 $x$，都有 $f_n(x) \ge 0$。

首先看等式左边。当 $n \to \infty$ 时，$f_n(x)$ 逐点收敛于 $0$（除了 $0$ 点，但单点测度为 $0$），因此 $\liminf_{n \to \infty} f_n(x) = 0$：

$$\int_{[0,1]} \left( \liminf_{n \to \infty} f_n \right) d\nu = \int_{[0,1]} 0 \, d\nu = 0$$

再看等式右边。对于每一个 $n$，积分值为：

$$\int_{[0,1]} f_n d\nu = \int_0^{1/n} n \cdot (-1) dx = -1$$

因此 $\liminf_{n \to \infty} \int f_n d\nu = -1$。

**结论**：

此时 $0 \not\le -1$，Fatou 引理对于带号测度失效。

### 3. “测度为 0 的集合其子集测度也为 0”失效的反例

**定理回顾**：对于正测度，若 $\mu(E) = 0$ 且 $A \subset E$，则 $\mu(A) = 0$。这是正测度中“零测集”定义的直观来源。

**失效原因**：在带号测度中，整体测度为 $0$ 可能仅仅是因为正负互相抵消了，它的内部可能“暗流涌动”。

**反例构造**：

在 $[-1, 1]$ 上定义带号测度 $\nu$，密度函数为奇函数：

$$f(x) = x$$

我们取全集 $E = [-1, 1]$。

**验证**：

由于 $f(x)$ 是奇函数，在对称区间上的积分为 $0$：

$$\nu(E) = \int_{-1}^1 x dx = 0$$

现在我们取 $E$ 的一个子集 $A = [0, 1] \subset E$，计算它的测度：

$$\nu(A) = \int_0^1 x dx = \frac{1}{2} \neq 0$$

**结论**：

$\nu(E) = 0$，但其子集 $\nu(A) > 0$。这完美解释了为什么在带号测度中，我们必须重新定义**零集**（Null set）：一个集合 $E$ 是零集，当且仅当对于任意可测子集 $F \subset E$，都有 $\nu(F) = 0$。
