## 1.1 Entire Functions and Maximum Modulus
(a) Prove that if $f$ is an entire function that satisfies
$$\sup_{|z|=R} |f(z)| \leq AR^k + B$$
for all $R > 0$, and for some integer $k \geq 0$ and some constants $A, B > 0$, then $f$ is a polynomial of degree $\leq k$.

(b) Show that if $f$ is holomorphic in the unit disc, is bounded, and converges uniformly to zero in the sector $\theta < \arg z < \varphi$ as $|z| \to 1$, then $f = 0$.

(c) Let $w_1, \ldots, w_n$ be points on the unit circle in the complex plane. Prove that there exists a point $z$ on the unit circle such that the product of the distances from $z$ to the points $w_j$, $1 \leq j \leq n$, is at least $1$. Conclude that there exists a point $w$ on the unit circle such that the product of the distances from $w$ to the points $w_j$, $1 \leq j \leq n$, is exactly equal to $1$.

(d) Show that if the real part of an entire function $f$ is bounded, then $f$ is constant.

### 1.1.1 Solution
(a) Let $n>k$ $\lvert f^{(n)}(z) \rvert\leq \frac{n!}{R^{n-1}}(AR^{k}+B)\leq n!\left( A+\frac{B}{R} \right)$ . When $R\to \infty$, we get $\lvert f^{(n)}(z) \rvert=0,\forall z\in \mathbb{C}$. So $f$ is a polynomial whose degree is less than k.

(b) Solution 1
WOLG, we assume $\theta=0$
Firstly, Since the uniform convergence, we can extend f on the boundary of the sector $f(z)=0,0<argz<\varphi,\lvert z \rvert\to1$
Noting that there is an integer $N$ s.t. $\frac{\varphi}{2}N>2\pi$, we can cover the disc with sectors $\left[ 0,\frac{\varphi}{2}  \right],\left[ \varphi,\frac{3\varphi}{2} \right],\dots,\left[  \frac{(N-1)\varphi}{2},\frac{N\varphi}{2} \right]$ . For any $z\in D$, $z$ must belong to at least one sector.
Let $F(z)=f(z)f(e^{-i \varphi/2})\dots f\left( e^{- \frac{(N-1)\varphi}{2}i} \right)$ which is holomorphic. Then we show that $F(z)\to0$ as $\lvert z \rvert\to1$ uniformally
Assume $\lvert z \rvert>1-\delta$, and for simplicity, we write $argz\in\left[ \frac{k\varphi}{2}, \frac{(k+1)\varphi}{2} \right]$ . Then $ze^{-i k\varphi/2}\in \{z\in D|\theta<argz<\varphi\}$, So $|f(ze^{-i k\varphi/2})|<\varepsilon$ 
With the boundary M, we write $\lvert F(z) \rvert\leq M^{N-1}\varepsilon$
So $\lvert F(z) \rvert\to0$ as $\lvert z \rvert\to1$ uniformlly. We can extend $F(z)=0,when \: \lvert z \rvert=1$
By maximum modulo principle, we have $f\equiv0$

## 1.2 Harmonic Functions Maximum Principle
(a) If $u$ is a non-constant real-valued harmonic function in a region $\Omega$, then $u$ cannot attain a maximum (or a minimum) in $\Omega$.

(b) Suppose that $\Omega$ is a region with compact closure $\overline{\Omega}$. If $u$ is harmonic in $\Omega$ and continuous in $\overline{\Omega}$, then
$$\sup_{z \in \Omega} |u(z)| \leq \sup_{z \in \overline{\Omega} - \Omega} |u(z)|.$$

### 1.2.1 Solution
(a) Let $\Omega$ be a region. Assume $\mathrm{Re}f(w_{0})=\sup_{z\in\Omega}\mathrm{Re}f(z)$ , $w_{0}\in\Omega$
By open-mapping theorem, we know for $U(w_{0})$, there is a neiborhood $V(f(w_{0}))\subset f(\Omega)$. So we can find $\xi\in V(f(w_{0}))$ s.t. $\mathrm{Re}\xi>\mathrm{Re}f(w_{0})$, which leads to a contradction.

(b) If u is constant, the equality holds. Assume u is not constant.
In a compact set, f can attain its maximum modulo on certain point $w_{0}$. From (a), we know $w_{0}\not\in\Omega$, Therefore, $w_{0}\in\bar{\Omega}-\Omega$, which completes the proof.

## 1.3 Simply Connected Sets
(a) An open set $\Omega \subset \mathbb{C}$ is convex if for any two points in $\Omega$, the straight line segment between them is contained in $\Omega$. Prove that a convex open set is simply connected.

(b) More generally, an open set $\Omega \subset \mathbb{C}$ is star-shaped if there exists a point $z_0 \in \Omega$ such that for any $z \in \Omega$, the straight line segment between $z$ and $z_0$ is contained in $\Omega$. Prove that a star-shaped open set is simply connected. Conclude that the slit plane $\mathbb{C}-\{(-\infty, 0)\}$ (and more generally any sector, convex or not) is simply connected.
### 1.3.1 Solution
(a) Let $\Omega$ be a convex open set.
$$
L(t)=(1-t) z+t w, \quad t \in[0,1] \tag{1}
$$

lies entirely in $\Omega$. Hence, $\Omega$ is path-connected.
Let $\gamma:[0,1] \rightarrow \Omega$ be a closed curve, so that $\gamma(0)=\gamma(1)$. Fix any point $z_0 \in \Omega$. Define the homotopy

$$
H(t, s)=(1-s) \gamma(t)+s z_0, \quad(t, s) \in[0,1] \times[0,1]
$$

 Continuity: $H$ is continuous as a linear combination of continuous functions.
Endpoints:
$H(t, 0)=\gamma(t)$
$H(t, 1)=z_0$ 
 Closed curve condition:
$$
H(0, s)=(1-s) \gamma(0)+s z_0=(1-s) \gamma(1)+s z_0=H(1, s)
$$
Therefore, since every point of $H([0,1],[0,1])$ is contained in $\Omega$ by (1), the homotopy is continuous.

(b) Similar to (a), we only need to set $z_{0}$ to be the point meeting the given condition.
For $\mathbb{C}-\{(-\infty,0)\}$, let $z_{0}=1$ so that $z_{0}$ can line up all points in $\Omega$
