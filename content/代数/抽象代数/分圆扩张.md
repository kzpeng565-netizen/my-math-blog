# 1. 分圆多项式

定义48.1 域$F$​上的$x^{n}-1$的分裂域称为$F$的n次分圆扩张.

定义 48.2 多项式
$$
\Phi(x)=\prod_{i=1}^{\varphi(n)}\left(x-\alpha_i\right)
$$
为 $\mathbb{Q}$ 上的 $n$ 次分圆多项式（cyclotomic polynomial），其中 $\alpha_i$ 是 $\mathbb{Q}$ 中单位元的 $n$ 次本原根．
具体来说, $\alpha=e^{\frac{2\pi k}{n}},\:gcd(k,n)=1$

- **分圆多项式是所有n次本原根为根的最小多项式, 它的分裂域就是$x^{n}-1$的分裂域, 也就是$K(\zeta_{n})$** 
- 扩张次数为$\varphi(n)$
- 分圆多项式是不可约多项式
- 分圆多项式的伽罗瓦群同构于$\mathbb{Z} /n\mathbb{Z}$​的乘法群
- **系数都是有理数:** 设 $\sigma \in G(K / \mathbb{Q})$ ．由于伽罗瓦群 $G(K / \mathbb{Q})$ 的自同构必置换单位元的 $n$ 次本原根，可以看出 $\sigma_x\left(\Phi_n(x)\right)=\Phi_n(x)$ ，其中 $\sigma_x: K[x] \rightarrow K[x]$ 是 $\sigma$ 的多项式扩张．因此，$\Phi_n(x)$的系数在**每个** $\sigma \in G(K / \mathbb{Q})$ 下不变，于是，$\Phi_n(x)$ 的所有系数都是有理数．

**n次根多项式拆解为因子分圆多项式乘积**: $U=\{1,\zeta,\dots,\zeta^{n-1}\}$, 设$U_{d}$​是满足阶$d\mid n$的n次根集合, $U_{d}$也恰好是**所有的d次本原单位根**(因为d整除n, n次本原单位根能够生成所有d次本原根, 而且$U_{d}$阶数都是d) , 因此, $\bigcup_{d|n}U_{d}$构成$U$的划分
  由于$x^{n}-1=\prod_{d|n}\left\{ \prod_{\zeta\in U_{d}}(x-\zeta) \right\}=\prod_{d\mid n}\Phi_{d}(x)$ 

例如, $n=6$, $d=1,2,3,6$
$\Phi_{1}(x)=x-1$, ${\Phi}_{2}(x)=x+1$, $\Phi_{3}(x)=\left( x-e^{\frac{2\pi i}{3}} \right)\left( x-e^{\frac{4\pi i}{3}} \right)=x^{2}+x+1$ 
$d=6:$ 6次本原根（即与6互质的 $k$ 对应的根， $k=1,5)$ 。它们是 $\zeta_6^1=e^{\pi i / 3}$ 和 $\zeta_6^5=e^{5 \pi i / 3}$ ，也就是 $(1+i \sqrt{3}) / 2$ 和 $(1-i \sqrt{3}) / 2$ 。
$$
\Phi_6(x)=\left(x-e^{\pi i / 3}\right)\left(x-e^{5 \pi i / 3}\right)=x^2-x+1
$$
$$
\begin{aligned}
x^{n}-1=\prod_{d \mid 6} \Phi_d(x) & =\Phi_1(x) \cdot \Phi_2(x) \cdot \Phi_3(x) \cdot \Phi_6(x) \\
& =(x-1)(x+1)\left(x^2+x+1\right)\left(x^2-x+1\right)
\end{aligned}
$$

- **归纳法证明$\Phi _n(x)\in \mathbb{Z}[x],\Phi_{n}(0)=1$** 
令$g(x)=\prod_{d|n,d\neq n}\Phi_{d}(x)$ 
$$
x^{n}-1=q(x)g(x)+r(x)\quad  deg(r)<deg(g)
$$
根据归纳, $g(x)\in \mathbb{Z}[x], x^{n}-1\in \mathbb{Z}[x]$ 所以$q(x)\in \mathbb{Z}[x]$
又$q(x)\Phi_{n}(x)=x^{n}-1$​, 我们有$q(x)=\Phi_{n}(x)$.
令$x=0$, 只有$\Phi_{1}(0)=-1$ 我们得到$\Phi_{n}(0)=1$ 


# 2. 添加单位根的伽罗瓦群

$U(\mathbb{Z}/n\mathbb{Z})$是$\mathbb{Z} /n\mathbb{Z}$​的乘法可逆群. 也就是所有与$n$互素的元素构成的群. 例如$n=6,U(\mathbb{Z} /n\mathbb{Z})=\{1,5\}$ 

>[!定理 5.49 ]
> 假设 $K$ 是由 $L$ 添加 $n$ 次本原单位根生成的域，那么 $K$ 是 $L$ 的伽罗瓦扩张．假设 $K$ 不等于 $L$，那么群 $\operatorname{Gal}(K / L)$ 与剩余类环 $\mathbb{Z} / n \mathbb{Z}$ 中乘法可逆元形成的群 $U(\mathbb{Z} / n \mathbb{Z})$ 的一个子群同构．

设 $\zeta_n$ 是一个 $n$ 次本原单位根。 $K=L\left(\zeta_n\right)$ 中任何元素都可以用 $\zeta_n$ 表示。
－伽罗瓦群 $\operatorname{Gal}(K / L)$ 中任何一个自同构 $\sigma$ ，完全由它作用在生成元 $\zeta_n$ 上的结果决定。
－由于 $\sigma$ **必须将本原单位根** $\zeta_n$ **映射到另一个本原单位根**（否则会破坏多项式关系），所以存在某个与 $n$ 互质的整数 $a$ ，使得 $\sigma\left(\zeta_n\right)=\zeta_n^a$ 。
－因此，我们可以建立一个自然的映射：

$$
\begin{aligned}
\operatorname{Gal}(K / L) & \longrightarrow U(\mathbb{Z} / n \mathbb{Z}) \\
\sigma & \longmapsto a(\bmod n) \quad \text { 其中 } \sigma\left(\zeta_n\right)=\zeta_n^a
\end{aligned}
$$

**特别地** 伽罗瓦群 $\operatorname{Gal}(K / L)$ 是**交换的**，当 $n$ 是**素数时**，这个伽罗瓦群是**循环群**． 

当 $L=\mathbb{Q}$ 时：
因为分圆多项式 $\Phi_n(x)$ 在 $\mathbb{Q}$ 上不可约，所以
$\left[\mathbb{Q}\left(\zeta_n\right): \mathbb{Q}\right]=\operatorname{deg} \Phi_n(x)=\varphi(n)$ 。因此：
$$
\operatorname{Gal}\left(\mathbb{Q}\left(\zeta_n\right) / \mathbb{Q}\right) \cong U(\mathbb{Z} / n \mathbb{Z}) .
$$

如果 $L$ 本身已经包含了某个 $d$ 次 $(d \mid n)$ 的本原单位根，那么 $\Phi_n(x)$ 在 $L$ 上可能会分解，导致 $\left[L\left(\zeta_n\right): L\right]<\varphi(n)$ 。此时伽罗瓦群只是 $U(\mathbb{Z} / n \mathbb{Z})$ 的一个真子群，映射不是满射。这个子群具体是什么，取决于 $L$ 中已有哪些单位根。

## 3. 例子：$\mathbb{Q}(\zeta_{12})$ 的子域

为了找出 $\mathbb{Q}(\zeta_{12})$ 的所有子域，我们使用伽罗瓦理论基本定理。

### 3.1 确定扩张次数和伽罗瓦群
- 扩张次数：$[\mathbb{Q}(\zeta_{12}) : \mathbb{Q}] = \phi(12) = 12(1-\frac{1}{2})(1-\frac{1}{3}) = 4$。
- 伽罗瓦群结构：$G = \text{Gal}(\mathbb{Q}(\zeta_{12})/\mathbb{Q}) \cong (\mathbb{Z}/12\mathbb{Z})^\times$。 $(\mathbb{Z}/12\mathbb{Z})^\times = \{1, 5, 7, 11\}$。由于其中每个元素的平方模12均为1，故 $G \cong V_4 \cong C_2 \times C_2$（Klein四元群）。

### 3.2 分析群的子群
$V_4$ 有以下子群：
1.  平凡子群 $\{1\}$，对应整个域 $\mathbb{Q}(\zeta_{12})$。
2.  整个群 $G$，对应基域 $\mathbb{Q}$。
3.  三个2阶子群（指数为2，对应二次子域）：
    - $H_1 = \{1, 5\}$
    - $H_2 = \{1, 7\}$
    - $H_3 = \{1, 11\}$

### 3.3 确定对应的子域（固定域）
$\zeta_{12} = e^{i \pi/6} = \frac{\sqrt{3}}{2} + \frac{1}{2}i$，故 $\mathbb{Q}(\zeta_{12}) = \mathbb{Q}(\sqrt{3}, i)$。
- **对应 $H_3 = \{1, 11\}$**： $\sigma_{11}(\zeta) = \zeta^{11} = \zeta^{-1} = \bar{\zeta}$（复共轭）。在 $\mathbb{Q}(\sqrt{3}, i)$ 中，复共轭固定 $\sqrt{3}$，将 $i$ 变为 $-i$。故固定域为 $\mathbb{Q}(\sqrt{3})$。
- **对应 $H_2 = \{1, 7\}$**： $\sigma_{7}(\zeta) = \zeta^{7} = -\zeta$。注意到 $\zeta^2 = e^{i\pi/3}$ 被 $\sigma_7$ 固定：$\sigma_7(\zeta^2) = (\zeta^7)^2 = \zeta^{14} = \zeta^2$。而 $\zeta^2 = \frac{1}{2} + i\frac{\sqrt{3}}{2}$，故固定域为 $\mathbb{Q}(\sqrt{-3})$（即 $\mathbb{Q}(\zeta_3)$）。
- **对应 $H_1 = \{1, 5\}$**： $\sigma_{5}(\zeta) = \zeta^{5} = -\frac{\sqrt{3}}{2} + \frac{i}{2}$。与 $\zeta = \frac{\sqrt{3}}{2} + \frac{i}{2}$ 比较，可见 $i$ 的部分不变，$\sqrt{3}$ 变号。故固定域为 $\mathbb{Q}(i)$（即 $\mathbb{Q}(\zeta_4)$）。

### 3.4 结论
$\mathbb{Q}(\zeta_{12})$ 的所有子域为：
1. $\mathbb{Q}$ (次数4)
2. $\mathbb{Q}(i)$ (次数2)
3. $\mathbb{Q}(\sqrt{3})$ (次数2)
4. $\mathbb{Q}(\sqrt{-3})$ (次数2)
5. $\mathbb{Q}(\zeta_{12}) = \mathbb{Q}(\sqrt{3}, i)$ (次数1)
