### 计算伽罗瓦扩张中间域的完整步骤

对于形如 $P(x) = x^4 + ax^2 + b$（在 $\mathbb{Q}$ 上不可约）的多项式，其分裂域 $K=\mathbb{Q}(\alpha, \beta)$ 的中间域计算，可遵循以下系统方法。

---

#### **第一步：判别伽罗瓦群的结构**

首先利用系数判断伽罗瓦群 $G = \operatorname{Gal}(K/\mathbb{Q})$ 的同构类型。该类型决定了中间域的数量与结构。

设 $\alpha, \beta$ 满足 $\alpha^2 + \beta^2 = -a, \alpha^2\beta^2 = b$。关键判别式如下：
1. 计算 $\alpha\beta = \sqrt{b}$。
2. 计算 $\alpha^2 - \beta^2 = \sqrt{a^2 - 4b}$。
3. 计算 $(\frac{\alpha}{\beta} - \frac{\beta}{\alpha})^2 = \frac{a^2-4b}{b}$。

**判别准则：**
- 若 $b$ 是 $\mathbb{Q}$ 中的平方数，则 $G \simeq V_4$ (克莱因四元群)。
- 若 $b$ 不是平方数，但 $b(a^2-4b)$ 是 $\mathbb{Q}$ 中的平方数，则 $G \simeq C_4$ (循环群)。
- 若以上两者均不成立，则 $G \simeq D_8$ (二面体群)。

#### **第二步：应用伽罗瓦基本定理确定子域框架**

伽罗瓦基本定理建立了子群与中间域的一一对应。子群 $H$ 的阶 $|H|$ 与其固定域 $K^H$ 的度数关系为：$[K^H : \mathbb{Q}] = |G| / |H|$。

因此，计算所有中间域等价于找出 $G$ 的所有子群，并确定其固定域。不同群结构的子群分布如下：

- **$G \simeq V_4$ ($|G|=4$)**
  - 子群：1个4阶群 ($G$本身)，3个2阶群，1个1阶群。
  - 对应中间域：基域 $\mathbb{Q}$， **3个二次扩张子域**，分裂域 $K$。

- **$G \simeq C_4$ ($|G|=4$)**
  - 子群：1个4阶群，1个2阶群，1个1阶群。
  - 对应中间域：基域 $\mathbb{Q}$， **1个二次扩张子域**，分裂域 $K$。

- **$G \simeq D_8$ ($|G|=8$)**
  - 子群：1个8阶群， **3个4阶子群**， **5个2阶子群**，1个1阶群。
  - 对应中间域：基域 $\mathbb{Q}$， **3个二次子域** (对应4阶子群)， **5个四次子域** (对应2阶子群)，分裂域 $K$。

#### **第三步：为每个子群寻找生成元（构造具体子域）**

确定了子域的数量和次数后，需在 $K$ 中寻找对应的生成元。

1.  **二次子域**：通常由 $K$ 中对所有 $\sqrt{\cdot}$ 符号保持或改变有特定对称性的元素生成。常见的候选生成元有：
    - $\alpha\beta = \sqrt{b}$
    - $\alpha^2$ 或 $\beta^2$ (它们是有理系数二次方程的根)
    - $\alpha^2 - \beta^2 = \sqrt{a^2 - 4b}$
    - 上述有理数的乘积，如 $(\alpha\beta)(\alpha^2 - \beta^2) = \sqrt{b(a^2-4b)}$。

2.  **四次子域** (主要出现在 $D_8$ 情况)：通常由单个根或其简单组合生成，或由两个不同的二次子域复合而成。常见的候选生成元有：
    - 单个根：$\alpha$, $\beta$。
    - 根的线性组合：$\alpha + \beta$, $\alpha - \beta$。
    - 根与二次域元素的乘积：如 $i\alpha$ (若 $i \in K$)。
    - 两个二次子域的复合：例如 $\mathbb{Q}(\sqrt{b}, \sqrt{a^2-4b})$。

#### **第四步：通过具体例子演示完整过程**
好的，已为您完整保留并梳理 $D_8$ 情形（以 $P(x) = x^4 - 4x^2 - 1$ 为例）的全部计算步骤与方法。

##### 例1：$P(x) = x^4 - 4x^2 - 1$

###### **步骤1：判别伽罗瓦群结构**
- 给定 $a = -4, b = -1$。
- 判别：
  1. $b = -1$ 不是有理数的平方数，故 $G$ 不是 $V_4$。
  2. $b(a^2-4b) = (-1)[(-4)^2 - 4*(-1)] = (-1)*(16+4) = -20$，不是有理数的平方数，故 $G$ 也不是 $C_4$。
- **结论**：$G \simeq D_8$ (8阶二面体群)。

###### **步骤2：根据群论确定子域框架**
- $|G| = 8$，分裂域 $K/\mathbb{Q}$ 的度为 8。
- $D_8$ 的子群结构（对应伽罗瓦基本定理）：
  - **1个8阶子群** ($D_8$自身) → 对应 $\mathbb{Q}$。
  - **3个4阶子群** → 对应 **3个二次子域** ($[子域:\mathbb{Q}]=8/4=2$）。
  - **5个2阶子群** → 对应 **5个四次子域** ($[子域:\mathbb{Q}]=8/2=4$）。
  - **1个1阶子群** ($\{e\}$) → 对应 $K$。
- **计算目标**：找出这 **3个二次子域** 和 **5个四次子域**。

###### **步骤3：计算根与基本不变量**
- 解 $y = x^2$ 的方程：$y^2 - 4y - 1 = 0$，得 $y = 2 \pm \sqrt{5}$。
- 定义根：
  - $\alpha = \sqrt{2 + \sqrt{5}}$ （正的实根）
  - $\beta = \sqrt{2 - \sqrt{5}}$ （由于 $2-\sqrt{5}<0$，此为虚根）
- 计算并简化基本量：
  1. $\alpha^2 = 2 + \sqrt{5}$
  2. $\alpha\beta = \sqrt{(2+\sqrt{5})(2-\sqrt{5})} = \sqrt{4-5} = \sqrt{-1} = i$。
  3. $\alpha^2 - \beta^2 = (2+\sqrt{5}) - (2-\sqrt{5}) = 2\sqrt{5}$。
- 分裂域：$K = \mathbb{Q}(\alpha, \beta) = \mathbb{Q}(\alpha, i)$ （因为 $\beta = i/\alpha$）。

###### **步骤4：构造所有二次子域（3个）**
二次子域由在 $D_8$ 作用下“变化不大”的元素（即属于某个4阶子群的不动域）生成。通常由判别式相关的平方根生成。
- 由 $\alpha^2 = 2+\sqrt{5}$ 可知 $\sqrt{5} \in K$，得子域 $\mathbb{Q}(\sqrt{5})$。
- 由 $\alpha\beta = i$，得子域 $\mathbb{Q}(i)$。
- 考虑 $\sqrt{5}$ 与 $i$ 的乘积：$\sqrt{5} \cdot i = i\sqrt{5}$，它生成子域 $\mathbb{Q}(i\sqrt{5})$。
- **验证**：这三个域互不相同且均为二次扩张。它们是：
  1. $F_1 = \mathbb{Q}(\sqrt{5})$
  2. $F_2 = \mathbb{Q}(i)$
  3. $F_3 = \mathbb{Q}(i\sqrt{5})$

###### **步骤5：构造所有四次子域（5个）**
四次子域对应 $D_8$ 的2阶子群。它们可以通过两种思路找到：
1. **由单个根或其简单变形生成**：这些域通常是 $K$ 的**非正规**子域。
2. **由两个不同的二次子域复合生成**：这个域是 $K$ 的**正规**子域（对应 $D_8$ 的中心子群）。

**具体构造：**
1. **$\mathbb{Q}(\alpha)$**：由于 $P(x)$ 不可约，$\alpha$ 的极小多项式为4次，故 $\mathbb{Q}(\alpha)$ 是4次域。它包含 $\sqrt{5}$ 但不包含 $i$。
2. **$\mathbb{Q}(\beta)$**：同理，$\beta$ 也生成一个4次域。注意 $\beta = i/\alpha \notin \mathbb{Q}(\alpha)$，所以这是一个不同的域。
3. **$\mathbb{Q}(i\alpha)$**：$i\alpha$ 是根 $\alpha$ 的一个变形，它生成另一个4次域。
4. **$\mathbb{Q}(i\beta)$**：同理，这是第四个由根变形生成的4次域。
5. **$\mathbb{Q}(\sqrt{5}, i)$**：这是由两个二次子域 $F_1$ 和 $F_2$ 复合而成的双二次域。由于它包含 $\sqrt{5}$ 和 $i$，其度数为 $2\times2=4$。它是 $K$ 中唯一的正规四次子域。

**验证次数与互异性**：
- 前四个域 $\mathbb{Q}(\alpha), \mathbb{Q}(\beta), \mathbb{Q}(i\alpha), \mathbb{Q}(i\beta)$ 均由一个4次无理数生成，且彼此不包含（因为它们固定的 $D_8$ 的子群不同）。
- 第五个域 $\mathbb{Q}(\sqrt{5}, i)$ 明显不同于前四个，因为它包含两个独立的二次无理数。
- 至此，**5个四次子域**已全部找到。

###### **步骤6：列出所有中间域**
从基域到分裂域的完整中间域格为：
- **次数1**：$\mathbb{Q}$
- **次数2**：$\mathbb{Q}(\sqrt{5})$, $\mathbb{Q}(i)$, $\mathbb{Q}(i\sqrt{5})$
- **次数4**：$\mathbb{Q}(\alpha)$, $\mathbb{Q}(\beta)$, $\mathbb{Q}(i\alpha)$, $\mathbb{Q}(i\beta)$, $\mathbb{Q}(\sqrt{5}, i)$
- **次数8**：$K = \mathbb{Q}(\alpha, i)$


**例2：$P(x) = x^4 - 6x^2 + 4$**
1.  **判别**：$a=-6, b=4$。$b=2^2$ 是有理数平方，故 $G \simeq V_4$。
2.  **框架**：应找到 **3个二次子域**。
3.  **计算**：
    - 根：$\alpha = \sqrt{3+\sqrt{5}} = \frac{1+\sqrt{5}}{\sqrt{2}}$, $\beta = \sqrt{3-\sqrt{5}} = \frac{\sqrt{5}-1}{\sqrt{2}}$。
    - $K = \mathbb{Q}(\sqrt{2}, \sqrt{5})$。
4.  **找二次子域**：即双二次域 $\mathbb{Q}(\sqrt{2}, \sqrt{5})$ 的三个二次子域。
    - $\mathbb{Q}(\sqrt{2})$
    - $\mathbb{Q}(\sqrt{5})$
    - $\mathbb{Q}(\sqrt{10})$

**例3：$P(x) = x^4 + 5x^2 + 5$**
1.  **判别**：$a=5, b=5$。
    - $b=5$ 非平方。
    - $b(a^2-4b)=5*(25-20)=25=5^2$ 是平方。
    - 故 $G \simeq C_4$。
2.  **框架**：应找到 **1个二次子域**。
3.  **计算**：
    - $a^2-4b = 5$，故 $\sqrt{a^2-4b} = \sqrt{5}$。
    - 唯一的二次子域是 $\mathbb{Q}(\sqrt{5})$。
    - 分裂域 $K = \mathbb{Q}\left(\sqrt{\frac{-5+\sqrt{5}}{2}}, \sqrt{\frac{-5-\sqrt{5}}{2}}\right)$ 是 $\mathbb{Q}(\sqrt{5})$ 上的二次循环扩张。

**总结：** 计算中间域的完整流程是：**判别群型 -> 确定子域数量与次数框架 -> 计算关键元素（根、平方根等） -> 利用对称性寻找对应次数的生成元**。
