## （1）证明 $K / \mathbb{Q}$ 是 Galois 扩张，并计算 $\operatorname{Gal}(K / \mathbb{Q})$

### 第一步：找出 $a = \sqrt{5 + \sqrt{21}}$ 满足的多项式
设  
$$
a = \sqrt{5 + \sqrt{21}}.
$$  
则  
$$
a^2 = 5 + \sqrt{21} \quad \Rightarrow \quad \sqrt{21} = a^2 - 5.
$$  
两边平方得  
$$
21 = (a^2 - 5)^2 = a^4 - 10a^2 + 25,
$$  
即  
$$
a^4 - 10a^2 + 4 = 0.
$$  
因此 $a$ 是多项式  
$$
f(x) = x^4 - 10x^2 + 4 \in \mathbb{Q}[x]
$$  
的一个根。

### 第二步：证明 $f(x)$ 在 $\mathbb{Q}$ 上不可约，且 $K$ 是 $f(x)$ 的分裂域
- **不可约性**：  
  检验有理根：常数项 $4$ 的因子为 $\pm 1, \pm 2, \pm 4$。直接验证 $f(\pm 1) = -5$, $f(\pm 2) = -20$, $f(\pm 4) = 196$，均不为零，故无一次因子。  
  假设 $f(x)$ 可分解为两个二次因式：
  $$
  x^4 - 10x^2 + 4 = (x^2 + Ax + B)(x^2 + Cx + D).
  $$  
  比较系数得方程组：
  $$
  \begin{cases}
  A + C = 0, \\
  B + D + AC = -10, \\
  AD + BC = 0, \\
  BD = 4.
  \end{cases}
  $$  
  由 $A + C = 0$ 得 $C = -A$；由 $AD + BC = A(D - B) = 0$，若 $A \neq 0$ 则 $D = B$；代入 $BD = B^2 = 4$ 得 $B = \pm 2$。  
  若 $B = 2$，则 $B + D + AC = 4 - A^2 = -10$，推出 $A^2 = 14$，无有理数解；若 $B = -2$，则 $-4 - A^2 = -10$，推出 $A^2 = 6$，亦无有理数解。  
  故 $f(x)$ 在 $\mathbb{Q}$ 上不可约，因此 $[K : \mathbb{Q}] = 4$。

- **分裂域**：  
  解方程 $x^4 - 10x^2 + 4 = 0$。令 $y = x^2$，得 $y^2 - 10y + 4 = 0$，解得  
  $$
  y = \frac{10 \pm \sqrt{100 - 16}}{2} = 5 \pm \sqrt{21}.
  $$  
  故 $f(x)$ 的四个根为：
  $$
  \alpha_1 = \sqrt{5 + \sqrt{21}},\quad 
  \alpha_2 = -\sqrt{5 + \sqrt{21}},\quad 
  \alpha_3 = \sqrt{5 - \sqrt{21}},\quad 
  \alpha_4 = -\sqrt{5 - \sqrt{21}}.
  $$  
  注意到  
  $$
  \alpha_1 \alpha_3 = \sqrt{(5 + \sqrt{21})(5 - \sqrt{21})} = \sqrt{25 - 21} = 2,
  $$  
  因此 $\alpha_3 = 2 / \alpha_1 \in \mathbb{Q}(\alpha_1) = K$。同理 $\alpha_2 = -\alpha_1$, $\alpha_4 = -\alpha_3$ 也在 $K$ 中。  
  所以 $K = \mathbb{Q}(\alpha_1)$ 包含 $f(x)$ 的所有根，即 $K$ 是 $f(x)$ 在 $\mathbb{Q}$ 上的分裂域。

- **Galois 性**：  
  由于 $\mathbb{Q}$ 的特征为 $0$，扩张自动可分；又因为 $K$ 是 $f(x)$ 的分裂域，故 $K/\mathbb{Q}$ 是正规扩张。综上，$K/\mathbb{Q}$ 是 Galois 扩张，且 $|\operatorname{Gal}(K/\mathbb{Q})| = [K : \mathbb{Q}] = 4$。

### 第三步：确定 $\operatorname{Gal}(K / \mathbb{Q})$ 的结构
Galois 群由根 $\{\alpha_1, \alpha_2, \alpha_3, \alpha_4\}$ 上的置换作用完全决定。定义以下自同构：

1. $\sigma: \alpha_1 \mapsto \alpha_3$。  
   由 $\alpha_1^2 = 5 + \sqrt{21}$，有 $\sigma(\alpha_1^2) = \alpha_3^2 = 5 - \sqrt{21}$，故 $\sigma(\sqrt{21}) = \sigma(\alpha_1^2 - 5) = \alpha_3^2 - 5 = -\sqrt{21}$。  
   进而：
   - $\sigma(\alpha_3) = \sigma(2/\alpha_1) = 2/\sigma(\alpha_1) = 2/\alpha_3 = \alpha_1$（因为 $2/\alpha_3 = \alpha_1$）。
   - $\sigma(\alpha_2) = \sigma(-\alpha_1) = -\alpha_3 = \alpha_4$。
   - $\sigma(\alpha_4) = \sigma(-\alpha_3) = -\alpha_1 = \alpha_2$。  
   易见 $\sigma^2 = \operatorname{id}$，故 $\sigma$ 的阶为 $2$。

2. $\tau: \alpha_1 \mapsto \alpha_2 = -\alpha_1$。  
   则 $\tau(\alpha_1^2) = (-\alpha_1)^2 = \alpha_1^2$，故 $\tau(\sqrt{21}) = \sqrt{21}$。  
   进而：
   - $\tau(\alpha_3) = \tau(2/\alpha_1) = 2/(-\alpha_1) = -\alpha_3 = \alpha_4$。
   - $\tau(\alpha_2) = \tau(-\alpha_1) = \alpha_1$。
   - $\tau(\alpha_4) = \tau(-\alpha_3) = \alpha_3$。  
   同样 $\tau^2 = \operatorname{id}$，阶为 $2$。

3. 复合 $\sigma\tau$：  
   $\sigma\tau(\alpha_1) = \sigma(-\alpha_1) = -\alpha_3 = \alpha_4$，  
   $\tau\sigma(\alpha_1) = \tau(\alpha_3) = -\alpha_3 = \alpha_4$，故 $\sigma\tau = \tau\sigma$。  
   直接验证 $(\sigma\tau)^2 = \operatorname{id}$。

因此 $\operatorname{Gal}(K/\mathbb{Q}) = \{ \operatorname{id}, \sigma, \tau, \sigma\tau \}$，其中所有非单位元阶均为 $2$，且两两交换。这正符合克莱因四元群的结构：
$$
\operatorname{Gal}(K/\mathbb{Q}) \cong V_4 \cong C_2 \times C_2.
$$

## （2）求 $K$ 的所有子域

根据 Galois 对应，$K/\mathbb{Q}$ 的中间域与 $\operatorname{Gal}(K/\mathbb{Q}) \cong V_4$ 的子群一一对应。$V_4$ 有 $5$ 个子群：
- $H_0 = \{ \operatorname{id} \}$（平凡子群）
- $H_1 = \{ \operatorname{id}, \sigma \}$
- $H_2 = \{ \operatorname{id}, \tau \}$
- $H_3 = \{ \operatorname{id}, \sigma\tau \}$
- $H_4 = V_4$（整个群）

每个子群 $H$ 的固定域 $K^H$ 即为对应的中间域。

### 1. $H_4 = V_4$ 的固定域
固定域为 $\mathbb{Q}$。

### 2. $H_1 = \{ \operatorname{id}, \sigma \}$ 的固定域
由于 $[K : K^{H_1}] = |H_1| = 2$，固定域应为二次扩张。寻找被 $\sigma$ 固定的元素。  
考虑  
$$
\alpha_1 + \alpha_3 = \sqrt{5 + \sqrt{21}} + \sqrt{5 - \sqrt{21}}.
$$  
计算  
$$
(\alpha_1 + \alpha_3)^2 = \alpha_1^2 + \alpha_3^2 + 2\alpha_1\alpha_3 = (5+\sqrt{21}) + (5-\sqrt{21}) + 4 = 14,
$$  
故 $\alpha_1 + \alpha_3 = \sqrt{14}$（取正根）。  
直接验证：$\sigma(\alpha_1 + \alpha_3) = \alpha_3 + \alpha_1 = \alpha_1 + \alpha_3$，且 $\tau(\alpha_1 + \alpha_3) = -\alpha_1 - \alpha_3 = -(\alpha_1 + \alpha_3)$。  
因此 $\sqrt{14}$ 被 $\sigma$ 固定，不被 $\tau$ 固定。所以  
$$
K^{H_1} = \mathbb{Q}(\sqrt{14}).
$$

### 3. $H_2 = \{ \operatorname{id}, \tau \}$ 的固定域
寻找被 $\tau$ 固定的元素。注意 $\tau(\sqrt{21}) = \sqrt{21}$，且 $\tau(\alpha_1) = -\alpha_1$，故 $\sqrt{21}$ 被固定。  
另一方面，$\sigma(\sqrt{21}) = -\sqrt{21}$，所以 $\sqrt{21}$ 仅被 $\tau$ 固定。因此  
$$
K^{H_2} = \mathbb{Q}(\sqrt{21}).
$$

### 4. $H_3 = \{ \operatorname{id}, \sigma\tau \}$ 的固定域
考虑  
$$
\alpha_1 - \alpha_3 = \sqrt{5 + \sqrt{21}} - \sqrt{5 - \sqrt{21}}.
$$  
计算  
$$
(\alpha_1 - \alpha_3)^2 = \alpha_1^2 + \alpha_3^2 - 2\alpha_1\alpha_3 = 10 - 4 = 6,
$$  
故 $\alpha_1 - \alpha_3 = \sqrt{6}$（取正根）。  
验证：$\sigma(\alpha_1 - \alpha_3) = \alpha_3 - \alpha_1 = -(\alpha_1 - \alpha_3)$，$\tau(\alpha_1 - \alpha_3) = -\alpha_1 - (-\alpha_3) = -(\alpha_1 - \alpha_3)$，但 $\sigma\tau(\alpha_1 - \alpha_3) = \sigma(\tau(\alpha_1 - \alpha_3)) = \sigma(-(\alpha_1 - \alpha_3)) = -(\alpha_3 - \alpha_1) = \alpha_1 - \alpha_3$。  
因此 $\sqrt{6}$ 被 $\sigma\tau$ 固定。所以  
$$
K^{H_3} = \mathbb{Q}(\sqrt{6}).
$$

### 5. $H_0 = \{ \operatorname{id} \}$ 的固定域
固定域为 $K$ 本身。

### 总结
$K$ 的所有子域（即 $\mathbb{Q}$ 与 $K$ 之间的中间域）为：
1. $\mathbb{Q}$
2. $\mathbb{Q}(\sqrt{14})$
3. $\mathbb{Q}(\sqrt{21})$
4. $\mathbb{Q}(\sqrt{6})$
5. $K = \mathbb{Q}\bigl(\sqrt{5 + \sqrt{21}}\bigr)$

这些域均为 $\mathbb{Q}$ 的二次扩张或四次扩张，且彼此互不相同（因为 $\sqrt{14}, \sqrt{21}, \sqrt{6}$ 在 $\mathbb{Q}$ 上线性无关）。

## 练习 4

设 $F=\mathbb{F}_{p}(T)$ 。设 $K$ 表示多项式

$$
f(x)=x^{2 p}+T x^{p}+T
$$

在 $F$ 上的分裂域。
（1）证明：$f(x)$ 在域 $F$ 上是不可约的。
（2）确定自同构群 $\operatorname{Aut}(K / F)$ 并计算 $[K: F]_{s}$ 。
（3）确定在 $\operatorname{Aut}(K / F)$ 作用下 $K$ 的不变子域。
（4）找出 $F$ 在 $K$ 中的可分闭包（即 $K$ 中所有对 $F$ 可分的元素生成的最大子域）。

**解**：设 $F=\mathbb{F}_{p}(T)$，$f(x)=x^{2p}+Tx^{p}+T \in F[x]$，$K$ 为 $f(x)$ 在 $F$ 上的分裂域。

**(1) 不可约性**  
将 $f(x)$ 视为 $\mathbb{F}_p[T]$ 上的多项式。由于 $T$ 是 $\mathbb{F}_p[T]$ 中的素元，且满足：
- $T$ 整除所有非首项系数（即 $T x^p$ 的系数 $T$ 和常数项 $T$），
- $T^2$ 不整除常数项 $T$，
- 首项系数 $1$ 不被 $T$ 整除，
由 Eisenstein 准则，$f(x)$ 在 $\mathbb{F}_p[T]$ 上不可约，从而在其分式域 $F=\mathbb{F}_p(T)$ 上也不可约。

**(2) 自同构群与可分次数**  
令 $u$ 为 $f(x)$ 的一个根。设 $w$ 满足 $w^p = T$，并记 $v = w/u$。直接验证表明 $f(x) = (x-u)^p (x-v)^p$，且 $\alpha = u^p$ 和 $\beta = v^p$ 是二次方程 $y^2 + Ty + T = 0$ 的两个根。分裂域 $K = F(u, w)$。

由于 $w^p = T \in F$，$w$ 在 $F$ 上的极小多项式为 $x^p - T$，故 $[F(w):F] = p$。进一步，$u$ 满足 $u^{2p} + w^p u^p + w^p = 0$，可证 $[K:F(w)] = 2p$，从而 $[K:F] = 2p^2$（$p$ 为奇数时；$p=2$ 时 $[K:F]=4$）。

考虑 $F$-自同构 $\sigma: K \to K$，由生成元的像决定。因为 $w^p = T$，$\sigma(w)$ 也满足 $x^p = T$，而 $x^p - T = (x-w)^p$ 在 $K$ 中仅有根 $w$，故 $\sigma(w) = w$。又 $\sigma(u)$ 必为 $f(x)$ 的根，故 $\sigma(u) = u$ 或 $\sigma(u) = v$。定义 $\sigma$ 为 $\sigma(u) = v$，$\sigma(w) = w$，则 $\sigma$ 是阶为 $2$ 的自同构，且 $\operatorname{Aut}(K/F) = \langle \sigma \rangle \cong \mathbb{Z}/2\mathbb{Z}$。

由于 $K/F$ 是正规扩张，$|\operatorname{Aut}(K/F)| = [K:F]_s$，故 $[K:F]_s = 2$。

**(3) 不变子域**  
令 $G = \operatorname{Aut}(K/F) = \langle \sigma \rangle$。不变子域 $K^G = \{ x \in K : \sigma(x) = x \}$。由于 $[K:K^G] = |G| = 2$，有 $[K^G:F] = [K:F]/2 = p^2$（$p$ 奇数）或 $2$（$p=2$）。$K^G$ 是 $F$ 在 $K$ 中的纯不可分闭包。

- 当 $p=2$ 时，$K^G = F(w) = F(\sqrt{T})$。
- 当 $p$ 为奇数时，$K^G = F(w, y)$，其中 $y = \dfrac{\alpha - \beta}{u - w/u}$，满足 $y^p = [T(T-4)]^{(p-1)/2} \in F$。这里 $w^p = T$，$\alpha, \beta$ 为 $y^2+Ty+T=0$ 的根。等价地，$K^G$ 是 $F$ 的 $p^2$ 次纯不可分扩张，由 $T$ 的 $p$ 次根和 $[T(T-4)]^{(p-1)/2}$ 的 $p$ 次根生成。

**(4) 可分闭包**  
$F$ 在 $K$ 中的可分闭包 $K_{\mathrm{sep}}$ 是 $K$ 中所有在 $F$ 上可分的元素生成的最大子域。由于 $[K:F]_s = 2$，$K_{\mathrm{sep}}$ 是 $F$ 的二次可分扩张。注意到 $\alpha = u^p$ 满足 $\alpha^2 + T\alpha + T = 0$，该二次多项式判别式为 $T(T-4) \in F$ 非平方，故 $F(\alpha)/F$ 是可分二次扩张。又 $\alpha \in K$，因此 $K_{\mathrm{sep}} = F(\alpha)$。

> 设 $\mathbf{E}$ 是域 $F$ 的有限扩张，那么 $E$ 是 $F[x]$ 中某有限个多项式集合的**分裂域**当且仅当对 $E$ 的每个扩张 $K$ ，以及每个**保持 $F$ 不变**且把 $E$ 映射到 $K$ 的一个子域上的**同构**$\sigma$， $\sigma$ 是 $E$ 的**自同构**．

$\phi:G\to G_{1}\times G_{2},\: \eta \to (\eta|_{K_{1}},\eta|_{K_{2}})$ 是良定义的, 依赖于这个定理.
由于$F\leq K_{1}\leq K_{1}K_{2}$​	, $\eta\in Gal(K_{1}K_{2} /F)$ $\eta|_{K_{1}}$是$K_{1}$上的自同构, 同理$\eta|_{K_{2}}$也是$K_{2}$上的自同构.
所以$\eta|_{K_{1}}\in G_{1},\eta|_{K_{2}}\in G_{2}$.
容易验证, $\phi$是同态.

1. $\phi$是单射. 如果$\eta|_{K_{1}}=id,\: \eta|_{K_{2}}=id$. 由于$K_{1}K_{2}$是由$K_{1} \cup K_{2}$生成的
2. $\mathrm{Im}\phi \subset H$. 对任意$\eta|_{K_{1}}(a)=\eta|_{K_{2}}(a),a\in K_{1}\cap K_{2}$.
3. $\mathrm{Im}\phi=H$​	 
   设$(\sigma,\tau)\in H$, 我们定义$\eta(x)=\sigma(a)\tau(b),\forall x=ab,a\in K_{1},b\in K_{2}$. 验证这个$\eta$是良定义的: $ab=a'b'\implies a'^{-1}a=b'b^{-1}\in K_{1}\cap K_{2}$ 所以$\sigma(a'^{-1}a)=\tau(b'b^{-1})\implies\sigma (a)\tau(b)=\sigma (a')\tau(b')$ 
   因此$\phi ^{-1}(\sigma,\tau)=\eta$. 是满射
4. 综上: $\phi$是$G\to H\leq Gal(K_{1} /F)\times Gal( K_{2} /F)$同构.

（3）在特殊情形 $F=K_{1} \cap K_{2}$ 下，证明
$$
\operatorname{Gal}\left(K_{1} K_{2} / F\right) \cong \operatorname{Gal}\left(K_{1} / F\right) \times \operatorname{Gal}\left(K_{2} / F\right)
$$
