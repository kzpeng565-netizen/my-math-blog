# 学期学习规划评分器

用于评价 `$study-planner` 是否正确把 `ToDo-任务集合.md` 中的课程作业规划到 `ToDo-已经规划好的任务.md`。

总分 100 分，达标线 85 分。

## 硬性退回规则

- 主动新增任务集合中没有的复习任务：最高 70 分。
- 把 Obsidian Tasks priority 符号解释成四象限：最高 75 分。
- 只在对话中输出而没有写入已规划文件：最高 75 分。
- 删除未成功规划或信息不足的任务块：最高 70 分。
- 没有读取可解析的 Obsidian 链接就估算作业题量：最高 78 分。
- Tasks 代码无法被 Obsidian Tasks 识别：最高 70 分。

## 1. 差异提取：15 分

- 只处理任务集合中的任务：4 分。
- 对照已规划文件避免重复：4 分。
- 正确识别由 `---` 分隔的任务块：3 分。
- 正确解析并保留作业 wikilink：3 分。
- 保留无法规划的任务：1 分。

## 2. Tasks 格式：25 分

- 使用 `- [ ] #task 任务名 [🍅:: 0/n] 优先级 ⏳ YYYY-MM-DD 📅 YYYY-MM-DD`：8 分。
- 使用正确的 priority 符号语义：5 分。
- `⏳` 与 `📅` 日期字段正确：4 分。
- 任务名称简洁：3 分。
- 不错误合并不同作业链接：3 分。
- 正确写入文件并安全移除已规划块：2 分。

## 3. 作业耗时：35 分

- 使用 20/40/60 分钟三档：8 分。
- 根据证明复杂度、计算量、查阅需要和小问数判断难度：9 分。
- 优先按 `[!Note]`、编号题目或显式问题提取题量：7 分。
- 按 `ceil(总分钟 / 40)` 换算番茄钟：5 分。
- 不机械地把所有题归入同一档：4 分。
- 不根据用户自评熟练度擅自增减时间：2 分。

## 4. 优先级与日期：25 分

- 尊重明确 DDL，并按课程规则处理可推断 DDL：7 分。
- scheduled day 不晚于截止日期：5 分。
- priority 与紧迫性、考试和课程重要性相符：6 分。
- 提供有限且可执行的冷启动建议：4 分。
- 对未知 DDL、题量或链接保留不确定性：3 分。

## 固定评分输出

```text
差异提取：__/15
Tasks 格式：__/25
作业耗时：__/35
优先级与日期：__/25
总分：__/100
是否达标：是/否
触发退回规则：无/...
必须修改：
1. ...
```

最终结果必须总分至少 85，格式至少 22，耗时至少 30，优先级与日期至少 20，且不触发硬性退回规则。
