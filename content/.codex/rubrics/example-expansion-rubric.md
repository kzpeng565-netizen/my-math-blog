# 例子扩展评分器

用于评价围绕用户给定 idea 生成的单个数学例子。目标是创造性、区分度、贴合度和构造过程透明，而不是批量生成浅例子。

总分 100 分。达标线 85 分。

## 类型标注

先判断例子类型：

- **A 类**：同一个知识点的类似例子。
- **B 类**：同一个知识范围内的类似例子，但不重复使用同一个定理/工具。
- **C 类**：不同知识范围，但体现同一个 idea 的例子。

必须输出：

```text
例子类型：A/B/C
选择理由：
```

## 硬性退回规则

出现以下任一情况，不能作为最终例子：

- 数学上错误。
- 没有验证前提和结论。
- 只是换符号、换名称、换维度。
- 没有说明它和已有例子的区别。
- 没有说明它如何贴合用户给定的 idea。
- 用户要求 B 类，但仍重复使用已有例子的核心定理/工具。
- 用户要求 C 类，但仍停留在同一个知识范围内。
- 没有构造思路。
- 没有完整构造过程。
- 关键试错过程只是空泛地说“尝试很多方法”。

封顶规则：

- 没有构造思路：最高 85。
- 没有完整构造过程：最高 80。
- 没有关键试错过程简述：最高 88。
- 区分度低于 20/25：必须重构，不允许只润色。
- 数学正确性低于 17/20：不得作为最终例子。

## 1. 贴合用户 idea：20 分

- **准确抓住用户给定 idea：7 分**
  - 7 分：例子清楚体现用户给定的核心 idea。
  - 5-6 分：大体贴合，但需要解释才能看出联系。
  - 2-4 分：联系较弱。
  - 0-1 分：基本跑题。
- **保留用户原始思考方向：4 分**
  - 4 分：没有强行改写用户的问题。
  - 3 分：略有改写但仍保留原方向。
  - 1-2 分：AI 自己换了问题。
  - 0 分：完全偏离。
- **指出 idea 在例子中的具体位置：5 分**
  - 5 分：明确指出 idea 出现在构造、证明、反例机制或关键步骤中。
  - 3-4 分：指出了位置但不够具体。
  - 1-2 分：只说“体现了这个思想”。
  - 0 分：没有解释。
- **能与已有例子形成对话：4 分**
  - 4 分：明确说明它补充、对照或延伸了已有例子。
  - 3 分：有对照但较粗略。
  - 1-2 分：只笼统说不同。
  - 0 分：没有和已有例子对话。

## 2. 区分度：25 分

按 A/B/C 类型使用不同判准。

### A 类：同一个知识点的类似例子

- **不是简单换皮：7 分**
  - 对象、条件、结论或证明路径至少有一个实质变化。
- **突出同一知识点的新侧面：7 分**
  - 如边界情况、失败条件、极小例子、非典型对象。
- **与已有例子形成清楚对照：5 分**
  - 能说清“已有例子说明 X，这个例子说明 Y”。
- **难度或视角有变化：3 分**
  - 更简单、更极端、更抽象或更接近应用。
- **能帮助巩固同一知识点：3 分**

### B 类：同一个知识范围，但不重复同一个定理/工具

- **知识范围一致：4 分**
  - 仍属于用户指定的大范围，如实分析、测度论、拓扑、代数。
- **核心工具不同：9 分**
  - 不重复已有例子的核心定理、技巧或构造。
- **idea 的表现方式不同：5 分**
  - 同一个 idea 通过另一种工具显现。
- **能扩展用户工具箱：4 分**
  - 让用户看到同一思想在本领域中的另一种用法。
- **与已有例子有明确边界：3 分**
  - 能说明为什么这不是原例子的变体。

### C 类：不同知识范围，但 idea 相同

- **知识范围确实不同：6 分**
  - 不是同一课程内的小范围变化。
- **共享 idea 清楚：8 分**
  - 能抽象出共同机制，而不是表面类比。
- **跨领域迁移有解释：5 分**
  - 说明原领域中的结构如何对应到新领域。
- **不牺牲数学准确性：4 分**
  - 类比不能偷换定义或过度类比。
- **能启发新问题或笔记主题：2 分**

## 3. 创造性：15 分

- **选例不陈旧：5 分**
  - 不是最常见的课本第一例，除非重新组织出新角度。
- **有意外性或启发性：5 分**
  - 读者会觉得“这个角度我没想到”。
- **能生成后续变体：3 分**
  - 例子可以自然扩展出新问题。
- **不过度复杂：2 分**
  - 创造性不是靠堆复杂对象实现。

## 4. 数学正确性与验证：20 分

- **对象定义清楚：4 分**
- **前提检查完整：5 分**
- **结论验证清楚：5 分**
- **没有偷换概念或过度类比：4 分**
- **不确定处明确标注：2 分**

## 5. 构造过程透明度：15 分

- **构造思路清楚：5 分**
  - 说明为什么想到这个方向。
- **完整过程可复现：5 分**
  - 给出从 idea 到对象再到验证的完整构造过程。
- **关键试错过程有价值：5 分**
  - 简述一个被放弃的候选及其失败原因，再说明最终例子的改进点。

## 6. 笔记价值与表达：5 分

- **适合写入笔记或博客：2 分**
- **能帮助以后识别同类题型：2 分**
- **符合中文数学笔记格式：1 分**

## 固定评分输出

```text
评分：
- 贴合用户 idea：__/20
- 区分度：__/25
- 创造性：__/15
- 数学正确性与验证：__/20
- 构造过程透明度：__/15
- 笔记价值与表达：__/5
- 总分：__/100

是否达标：是/否
需要修改：
1. ...
2. ...
```

## 达标规则

最终例子必须同时满足：

- 总分至少 85。
- 贴合用户 idea 至少 16/20。
- 区分度至少 20/25。
- 创造性至少 10/15。
- 数学正确性至少 17/20。
- 构造过程透明度至少 12/15。

若未达标，优先修改最低分项。若区分度不达标，重构例子；若数学正确性不达标，重做或标注为探索性候选。
