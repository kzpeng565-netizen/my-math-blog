# 数学博客写作评分器（参考文章版）

这个评分器用于评价数学草稿是否被整理成了符合用户现有风格的中文解说性博客。参考文章的共同点不是固定格式，而是都有一个清楚的写作发动机：

- `波动方程的能量乘子法`：直接求导法在变区域上很笨，于是改用时空散度和边界通量。
- `不保持基点的同伦等价会有什么麻烦`：自由同伦不是不能用，而是函子性需要路径共轭修正。
- `形变收缩但不是强形变收缩的例子`：这个例子难想象，关键在于同伦的连续性会同时控制空间和时间方向。

高分文章必须让读者感到：**这里确实有一个麻烦，某个构造/例子/计算正好击中了这个麻烦，并且最后能带走一个以后还会用到的判断方式。**

总分 100 分。达标线 85 分。若未达标，必须先修改最低分项再输出最终稿。

## 评分前先写出三件事

评分前必须先在心里或报告中确定：

```text
文章发动机：这篇文章为什么非写不可？
破局动作：文章中真正让问题动起来的动作是什么？
证据载体：哪个例子、计算、图像、定理或反例承担了论证功能？
```

如果这三项说不清，文章通常不能超过 82 分。

## 硬性封顶规则

- **没有文章发动机**：只是在介绍一个知识点，不知道为什么要写，最高 78 分。
- **破局点只是口号**：只说“核心思想是……”但没有具体动作、构造或机制，最高 82 分。
- **例子/公式/图像只是摆设**：没有推进论证或解释麻烦，最高 84 分。
- **强行套模板**：机械使用 `The Setup / Heuristic / Key Trick / Reflection` 等固定结构，最高 80 分。
- **教科书化铺陈**：大量背景介绍挤掉用户自己的问题意识，最高 75 分。
- **虚构材料**：新增草稿中没有的定理、反例、应用、历史背景或结论，最高 60 分。
- **虚构直觉或类比**：为了写得“大白话”而发明用户没有提供的比喻，最高 70 分。
- **数学关键错误**：关键定义、假设、推理或结论错误，最高 70 分；若错误影响主结论，不得作为最终稿。
- **读完不能指导下次怎么做**：虽然正确，但没有形成可迁移的判断方式，最高 86 分。

## 1. 文章发动机与问题压力：18 分

评价文章有没有像参考文那样先制造一个具体的“麻烦感”。

- **开头能给出写作契约：4 分**
  - 4 分：开头几句说明本文要解决的麻烦、对比或困惑。
  - 2-3 分：有主题，但麻烦感较弱。
  - 0-1 分：像百科条目或课堂笔记开头。
- **问题压力具体：5 分**
  - 5 分：能指出具体卡点，如变限积分、基点漂移、强形变收缩的连续性约束。
  - 3-4 分：知道有问题，但卡点不够尖。
  - 1-2 分：只说“这个很重要/很抽象/很难”。
  - 0 分：没有问题压力。
- **主线贯穿全文：4 分**
  - 每一节都在回应最初的麻烦，而不是并列堆材料。
- **文章价值不是补全知识点：3 分**
  - 文章的价值来自一个视角、技巧、反例或修正，而不是把定义和定理讲全。
- **保留作者自己的疑问感：2 分**
  - 能保留“为什么这样做”“问题出在哪里”“这并非灾难”等作者式追问。

## 2. 破局动作与机制解释：24 分

评价文章有没有抓住真正让问题动起来的动作。高分文章的破局点应当像“乘 $u_t$ 构造散度场”“追踪基点路径产生共轭”“用一致连续性控制整条时间柱”这样具体。

- **破局动作具体可执行：6 分**
  - 6 分：明确说出对象、动作和结果，例如“把 $(t,x)$ 合成时空变量并构造通量场”。
  - 4-5 分：有动作，但对象或结果不够清楚。
  - 1-3 分：只有抽象口号。
  - 0 分：没有破局动作。
- **解释为什么要这样选：5 分**
  - 说明这个乘子、路径、空间、邻域、反例为什么自然，而不是直接宣布。
- **说明它解决了哪个障碍：5 分**
  - 必须把破局动作和前面的麻烦接上：它绕开了什么、修正了什么、暴露了什么。
- **机制不是一次性标题：4 分**
  - 后文计算、例子或变体持续回到这个机制，而不是标题里说完就消失。
- **保留关键条件的作用：4 分**
  - 例如基点、边界条件、紧性、一致连续性、非交换性、侧面通量等条件要解释其功能。

## 3. 证据载体的论证功能：18 分

评价例子、公式、图像、反例、变体是否真正承担论证功能。

- **例子不是装饰：5 分**
  - 例子必须暴露麻烦、排除误解或展示机制。
  - 低分表现：只是举一个常见例子，没有说明为什么非它不可。
- **有筛选或对比意识：4 分**
  - 像“圆的基本群交换，所以真正要看非交换情形”这样，能说明为什么普通例子不够。
- **公式服务于概念：3 分**
  - 公式不是越多越好；关键公式要承担“把想法落地”的功能。
- **图像/截图/Callout 与正文咬合：3 分**
  - 图片、手稿、Note 块应当被正文解释其作用，不只是插入。
- **能从局部证据推出一般启示：3 分**
  - 例子或计算之后，要回到更一般的判断方式或使用提醒。

## 4. 数学可靠性与条件追踪：16 分

评价文章是否在保持解说性的同时不牺牲数学准确性。

- **对象和符号设定清楚：3 分**
  - 读者能知道空间、映射、方程、基点、边界、参数分别是什么。
- **关键假设不丢：4 分**
  - 不省略支撑结论的条件，例如道路连通、边界条件、紧性、非交换性、正则性等。
- **关键推理有验证：4 分**
  - 对最关键一步要有足够解释，不能只说“显然”。
- **边界/例外/修正被追踪：3 分**
  - 能说明什么时候需要修正、什么时候普通方法够用、什么时候条件会失败。
- **不确定处明确标注：2 分**
  - 草稿缺条件、图像缺失或证明未完成时要标注，而不是替用户脑补。

## 5. 用户文风与思考痕迹：14 分

评价文章是否贴合参考文的真实气质：直接、紧凑、有作者的思考路径，而不是精致但空。

- **语言紧凑但不干瘪：4 分**
  - 段落短，句子有功能；不堆“优美、深刻、非常重要”。
- **保留思考转折：3 分**
  - 合理使用“然而”“问题出在”“注意到”“因此我们真正需要考虑”等转折，展示思路推进。
- **不过度润色成教科书腔：3 分**
  - 可以有一点个人笔记的锋利和粗粝，不必每段都学术化。
- **结尾给出可操作提醒：4 分**
  - 类似“以后用 Van Kampen 要追踪基点”“乘子法是在选几何通量”“强形变收缩卡在连续性”。

## 6. Obsidian/Quartz 格式与阅读节奏：10 分

- **开头摘要或引用块有效：2 分**
  - 可以用 `>` 给出核心外卖，但不要机械强制。
- **标题层级自然：2 分**
  - 标题围绕文章动作命名，而不是通用模板。
- **LaTeX 规范：2 分**
  - 行内公式用 `$...$`，重要公式用 `$$...$$`。
- **段落和公式间距紧凑：2 分**
  - 公式前后不堆多余空行；长公式后要接解释。
- **适合笔记库复用：2 分**
  - 读者以后能把其中的 trick、例子或提醒快速定位出来。

## 固定评分输出

当用户要求评分或 review 时，使用：

```text
文章发动机：
破局动作：
证据载体：

文章发动机与问题压力：__/18
破局动作与机制解释：__/24
证据载体的论证功能：__/18
数学可靠性与条件追踪：__/16
用户文风与思考痕迹：__/14
Obsidian/Quartz 格式与阅读节奏：__/10
总分：__/100
是否达标：是/否
触发封顶规则：无/...
最低分项：
必须修改：
1. ...
2. ...
```

## 达标规则

最终稿必须同时满足：

- 总分至少 85。
- 文章发动机与问题压力至少 15/18。
- 破局动作与机制解释至少 20/24。
- 证据载体的论证功能至少 15/18。
- 数学可靠性与条件追踪至少 13/16。
- 没有触发硬性封顶规则。

## 修改优先级

若未达标，按下面顺序修：

1. **先修文章发动机**：重写开头和第一节，让读者知道这篇文章在解决什么麻烦。
2. **再修破局动作**：把“核心思想”改写成“对象 + 动作 + 解决的障碍”。
3. **再修证据载体**：删掉无功能的例子/公式，补上为什么这个例子或计算承担论证作用。
4. **最后压缩水分**：删除教科书背景、空泛比喻、漂亮但没有信息量的句子。

评分器的目标不是逼出一篇完美论文，而是逼出一篇有个人问题意识、有数学动作、有可复用洞见的博客。
