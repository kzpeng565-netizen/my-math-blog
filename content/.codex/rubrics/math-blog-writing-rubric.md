# 数学博客写作评分器

用于评价由数学草稿、作业反思、手写讲解或零散笔记生成的中文解说性博客。目标不是把内容写长，而是把核心问题、破局点和数学启示写清楚。

总分 100 分。达标线 85 分。若未达标，必须先修改最低分项再输出最终稿。

## 硬性封顶规则

- 出现草稿中没有的定理、反例、应用、背景或结论：最高 60 分。
- 自行发明类比、直觉或故事来填充篇幅：最高 70 分。
- 文章强行套用固定模板，导致材料不自然：最高 80 分。
- 没有清楚的核心问题或主线：最高 82 分。
- 主要内容是教科书式背景铺陈，而不是处理用户草稿的洞见：最高 75 分。
- 数学表述有明显错误或关键假设缺失：最高 70 分；若错误影响主结论，不得作为最终稿。

## 1. 忠实度与材料边界：25 分

- **只使用给定材料：8 分**
  - 8 分：所有内容都能回到草稿、当前笔记或用户明确指令。
  - 5-7 分：有少量自然补足，但未改变主线。
  - 1-4 分：加入了较多未经授权的背景或推论。
  - 0 分：主要内容脱离草稿。
- **不幻觉数学内容：7 分**
  - 7 分：没有新增未提到的定理、例子、反例、应用。
  - 4-6 分：新增内容较轻，但可能让读者误以为来自草稿。
  - 1-3 分：明显自行扩写数学事实。
  - 0 分：关键结论是编造或未经支持的。
- **保留用户原始关注点：4 分**
  - 保留草稿中的破局点、困惑、对比、手稿标记或重点。
- **正确处理繁琐推导：3 分**
  - 应概括目的或使用截图占位，不擅自补完整段计算。
- **标注不确定处：3 分**
  - 条件、符号、图片缺失时要说明，不默默修补。

## 2. 文章主线与结构自然度：20 分

- **核心问题清楚：5 分**
  - 开头能让读者知道这篇文章要解决什么麻烦。
- **结构由材料生长出来：5 分**
  - 不强行使用固定三段式；标题层级服务于内容。
- **推进有张力：4 分**
  - 能呈现“为什么普通做法不够 / 为什么这个构造有用 / 为什么这个例子有麻烦”。
- **模块取舍克制：3 分**
  - 没有为了完整模板硬塞 Setup、Intuition、Reflection。
- **结尾回到洞见：3 分**
  - 结尾不是套话，而是回收文章真正得到的观点。

## 3. 洞见密度与解说价值：25 分

- **准确提炼破局点：7 分**
  - 能说清真正让问题动起来的 trick、构造、视角或对比。
- **解释为什么有效：6 分**
  - 不只说“使用某方法”，还说明这个方法解决了哪个障碍。
- **复杂构造背后的逻辑：5 分**
  - 对乘子、反例、同伦条件、边界条件等复杂对象，要解释“为什么这样选”。
- **避免证明复读：3 分**
  - 不把博客写成逐行证明转写。
- **形成可迁移观点：4 分**
  - 读者能带走一个可复用的数学思想或识别模式。

## 4. 简洁度与反注水：15 分

- **没有教科书式铺垫：4 分**
- **没有空泛大白话：4 分**
- **语言紧凑：3 分**
  - 每段承担一个功能，少用“非常重要”“显然很优美”等空评价。
- **公式只在必要处出现：2 分**
- **篇幅匹配草稿密度：2 分**
  - 短草稿不扩成长文；长草稿也要压出骨架。

## 5. 风格与 Markdown：15 分

- **贴合用户现有博客风格：5 分**
  - 问题意识强、对比清楚、局部有洞见，整体不水。
- **标题和小节自然：3 分**
  - 可以有标题，但不要每篇都长得一样。
- **LaTeX 规范：3 分**
  - 行内公式用 `$...$`，重要公式用 `$$...$$`。
- **引用块/加粗使用克制：2 分**
  - 只突出核心外卖或关键句。
- **适合 Obsidian/Quartz 阅读：2 分**
  - 段落短，层级清楚，没有多余空行。

## 固定评分输出

当用户要求评分或 review 时，使用：

```text
忠实度与材料边界：__/25
文章主线与结构自然度：__/20
洞见密度与解说价值：__/25
简洁度与反注水：__/15
风格与 Markdown：__/15
总分：__/100
是否达标：是/否
触发封顶规则：无/...
最低分项：
必须修改：
1. ...
2. ...
```

## 达标规则

最终稿必须同时满足：

- 总分至少 85。
- 忠实度与材料边界至少 21/25。
- 洞见密度与解说价值至少 20/25。
- 简洁度与反注水至少 12/15。
- 没有触发硬性封顶规则。

若忠实度不达标，删去或标注所有未经支持的内容。若洞见密度不达标，重写主线和破局点。若反注水不达标，压缩背景、类比和套话。
