# 假期综合任务规划评分器

用于评价 `$task-planner` 是否把学习、生活、家教与固定事项转化为容量真实、可以执行的 Obsidian Tasks 计划。

总分 100 分，达标线 85 分。

## 硬性退回规则

- 主动添加任务集合或用户输入中没有的目标、习惯、复习或预约：最高 65 分。
- 忽略固定事件、通勤或已经确认的时间冲突：最高 70 分。
- 把未确认的家教订单当作确定授课安排：最高 70 分。
- 使用虚构 DDL，或把 scheduled day 复制为假 deadline：最高 75 分。
- 只在对话中输出而没有写入已规划文件：最高 75 分。
- 删除未成功规划、边界不清或仍含未解决事项的源内容：最高 65 分。
- Tasks 代码无法被 Obsidian Tasks 识别：最高 70 分。

## 1. 提取与建模：20 分

- 读取任务集合、已规划文件和必要 wikilink：5 分。
- 避免重复规划，并保留身份相关的 wikilink：4 分。
- 正确区分学习、生活、家教获客、家教履约和固定事件：4 分。
- 提取完成条件、依赖、地点、日期和不确定性：4 分。
- 不编造缺失任务或上下文：3 分。

## 2. 拆分与估时：25 分

- 将长期目标转成周里程碑和近期行动：6 分。
- 任务粒度可独立执行，不过度拆分或错误合并：5 分。
- 数学习题正确使用 20/40/60 分钟档：4 分。
- 阅读、写作按可见范围和产出估计：4 分。
- 生活和家教计入准备、通勤、等待与跟进：4 分。
- 信息不足时保留不确定性：2 分。

## 3. 容量与排期：30 分

- 先扣除固定事项和通勤，再分配弹性任务：6 分。
- 保留约 15–20% 缓冲，不排满全部时间：5 分。
- 未来 1–7 天具体、远期使用里程碑而非假精确：5 分。
- 深度任务与低能耗任务放在合适时段：4 分。
- 日期、依赖和 priority 合理：5 分。
- 超容量时明确延期和取舍，不双重占用时间：5 分。

## 4. 输出与安全回写：25 分

- Tasks 语法、番茄钟、priority、`⏳` 与 `📅` 正确：7 分。
- 没有真实 DDL 时正确省略 `📅`：4 分。
- 任务名称简短并具有可验证完成条件：3 分。
- 只追加新内容，不覆盖或重排历史计划：4 分。
- 只移除已成功规划且边界明确的源单元：4 分。
- 最终报告写入内容、冲突、保留项和移除项：3 分。

## 固定评分输出

```text
提取与建模：__/20
拆分与估时：__/25
容量与排期：__/30
输出与安全回写：__/25
总分：__/100
是否达标：是/否
触发退回规则：无/...
必须修改：
1. ...
```

最终结果必须总分至少 85，拆分与估时至少 21，容量与排期至少 25，输出与安全回写至少 21，且不触发硬性退回规则。
