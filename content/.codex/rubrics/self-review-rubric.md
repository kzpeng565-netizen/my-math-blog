# Self Review Loop Rubric

Use this meta-rubric when a task-specific rubric is absent.

Threshold: 85/100. Stop after three iterations unless the user asks to continue.

- Task fit: 25
- Mathematical reliability: 25
- Preservation of user intent: 20
- Clarity and formatting: 15
- Actionability: 15

Loop:

1. Draft or edit.
2. Score each dimension.
3. Identify the two weakest dimensions.
4. Revise only what addresses those weaknesses.
5. Rescore.
6. Stop when threshold is met or when further improvement requires user input.
