# 中文命令速查

Claudian 的 Codex 补全主要使用 `$技能名`。下面是中文名称和实际调用名的对应关系。

默认规则：没有明确说“写进文章/修改当前笔记/插入到这里”时，只在对话框输出。明确要求写入时，普通局部修改直接执行；只有全文重构、结构调整、大幅删改或高风险数学修改才先给 EditPlan。

| 中文名称 | 实际调用 |
|---|---|
| 笔记排版 | `$note-layout` |
| 作业排版 | `$homework-layout` |
| AI内容格式整理 | `$ai-content-format-cleanup` |
| 数学笔记编辑 | `$math-note-editor` |
| 例子与反例 | `$math-example-builder` |
| 文章结构整理 | `$math-article-structure` |
| 自我评分迭代 | `$self-review-loop` |
| 证明解释评分 | `$review-proof-explanation` |
| PDF正文搜索 | `$pdf-search` |

## 常用说法

```text
$note-layout
请排版当前笔记，尽量保留原内容和表达。
```

```text
$homework-layout
请排版这些作业题，不要添加答案。
```

```text
$ai-content-format-cleanup
请整理这段 AI 内容，去掉多余标题，公式改成 $ 和 $$。
```

```text
$review-proof-explanation
请按证明解释评分器评价这段证明解释，只评分，不修改。
```
