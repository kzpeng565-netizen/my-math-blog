以下是这几个空间的整系数同调群（所有未写出的维数均为 $0$）：

- **$S^1$**  
  $H_0 = \mathbb{Z}$，$H_1 = \mathbb{Z}$，$H_{k\ge 2} = 0$。

- **$S^1 \vee S^1$**  
  $H_0 = \mathbb{Z}$，$H_1 = \mathbb{Z} \oplus \mathbb{Z}$，$H_{k\ge 2} = 0$。

- **闭曲面（closed surface）**  
  若为**可定向**亏格 $g$ 的闭曲面 $\Sigma_g$：  
  $H_0 = \mathbb{Z}$，$H_1 = \mathbb{Z}^{2g}$，$H_2 = \mathbb{Z}$。  
  若为**不可定向**亏格 $h$（$h$ 个交叉帽）的闭曲面 $N_h$：  
  $H_0 = \mathbb{Z}$，$H_1 = \mathbb{Z}^{h-1} \oplus \mathbb{Z}/2\mathbb{Z}$，$H_2 = 0$。

- **$\mathbb{RP}^n$**  
  - $n=1$：同 $S^1$，$H_0=\mathbb{Z}$，$H_1=\mathbb{Z}$。  
  - $n$ 为偶数（$n\ge 2$）：  
    $H_0 = \mathbb{Z}$，  
    $H_k \cong \mathbb{Z}/2\mathbb{Z}$（$k$ 为奇数，$1\le k < n$），  
    $H_n = 0$，其余为 $0$。  
  - $n$ 为奇数（$n\ge 3$）：  
    $H_0 = \mathbb{Z}$，  
    $H_k \cong \mathbb{Z}/2\mathbb{Z}$（$k$ 为奇数，$1\le k < n$），  
    $H_n = \mathbb{Z}$，其余为 $0$。

- **$\mathbb{CP}^n$**  
  $H_0 = \mathbb{Z}$，$H_2 = \mathbb{Z}$，$H_4 = \mathbb{Z}$，…，$H_{2n} = \mathbb{Z}$；  
  所有奇数维同调群为 $0$，维数 $>2n$ 也为 $0$。
