### 工具一：基础构件 —— 贴加单个胞腔的同调群变化

这是计算同调群最基础的逻辑，用于分析当我们往一个已知空间 $A$ 上贴一个新的 $k$ 维圆盘（胞腔）时，同调群会发生什么变化。
- **前提与定义**：有一个已知空间 $A$，以及一个 $k$ 维圆盘 $D^k$（$k \ge 2$）。通过一个映射 $f: S^{k-1} \to A$（即将圆盘的边界映射到 $A$ 上），将 $D^k$ 贴合到 $A$ 上，形成新空间 $A \cup_f D^k$。
- **计算公式（结论）**：新空间的同调群 $H_q(A \cup_f D^k)$ 完全取决于贴附映射 $f$ 诱导的 $\alpha_f$ 的阶数，分为以下四种情况：
    1. 当 $q \neq k-1, k$ 时：$H_q(A \cup_f D^k) \cong H_q(A)$（其他维度的同调群不受影响）。
    2. 当 $q = k-1$ 时：$H_{k-1}(A \cup_f D^k) \cong H_{k-1}(A) / \langle \alpha_f \rangle$（原同调群商去 $\alpha_f$ 生成的子群）。
    3. 当 $q = k$ 且 $\alpha_f$ 是无穷阶时：$H_k(A \cup_f D^k) \cong H_k(A)$。
    4. 当 $q = k$ 且 $\alpha_f$ 是有限阶时：$H_k(A \cup_f D^k) \cong H_k(A) \oplus \mathbb{Z}$。
- **作用**：适用于结构非常简单的空间，或者通过一步步贴加胞腔来递推计算。

| 情况                               | $\alpha_f$ 在哪里    | 结果直觉                                 |
| :------------------------------- | :---------------- | :----------------------------------- |
| $\alpha_f=a \in \mathbb{Z}$      | 无穷阶，primitive     | 把一个洞填死                               |
| $\alpha_f=2 a \in \mathbb{Z}$    | 无穷阶，non－primitive | 产生 $\mathbb{Z} / 2$ torsion，RP2 属于这个 |
| $\alpha_f \in \mathbb{Z} / 2$ 非零 | 有限阶               | 杀torsion，同时新增一个 $k$ 维自由类             |
| $\alpha_f=0$                     | 有限阶，平凡元           | 新增一个 $k$ 维洞                          |
### 工具二：终极武器 —— 胞腔同调（Cellular Homology）计算法
这是你**考试绝对的重点**。对于任意一个给定的胞腔复形，通过构建“胞腔链复形”来直接计算同调群，避免了复杂的拓扑空间操作，完全转化为线性代数（矩阵）和群论的计算。
#### 前提：理解骨架 (Skeleton)
- **含义**：一个胞腔复形 $X$ 是由低维到高维一步步构建的：$X_0 \subset X_1 \subset X_2 \dots \subset X_n = X$。
- $X_0$ 是一堆点（0-骨架）。
- $X_i$（i-骨架）是在 $X_{i-1}$ 的基础上，贴上若干个 $i$ 维圆盘（$i$-cells）得到的。
#### 考试标准计算流程（四步走）
**第一步：列出链群 (Chain Groups)**
根据引理 4.8.1，第 $k$ 个链群 $C_k = H_k(X_k, X_{k-1})$ 是一个**自由阿贝尔群**，它的秩（生成元的个数）正好等于 $X$ 中 **$k$ 维胞腔的个数**。
- _操作_：数一数空间有几个 $k$ 维胞腔。如果有 3 个，那 $C_k \cong \mathbb{Z} \oplus \mathbb{Z} \oplus \mathbb{Z}$。
- _记法_：$H_k(X_k, X_{k-1}) = \bigoplus_{\alpha \in \Lambda_k} \mathbb{Z}\{e_\alpha^k\}$，其中 $e_\alpha^k$ 代表具体的 $k$ 维胞腔。
**第二步：计算边界映射 (Cellular Boundary Formula)**
这是整个计算的**核心难点**。边界映射 $d_k: H_k(X_k, X_{k-1}) \to H_{k-1}(X_{k-1}, X_{k-2})$ 把 $k$ 维胞腔映射到 $(k-1)$ 维胞腔上。
- _公式_：$d_k(e_\alpha^k) = \sum_{\beta} d_{\alpha\beta} e_\beta^{k-1}$。
- _系数 $d_{\alpha\beta}$ 的含义_：$d_{\alpha\beta} = \operatorname{deg}(f_{\alpha\beta})$，即映射的**度 (degree)**。它表示第 $\alpha$ 个 $k$-cell 的边界，在贴附到 $(k-1)$-骨架时，缠绕了第 $\beta$ 个 $(k-1)$-cell 多少圈。
- _如何求 $\operatorname{deg}(f_{\alpha\beta})$_：考虑贴附映射 $f_\alpha: S^{k-1}_\alpha \to X_{k-1}$，然后将 $X_{k-1}$ 中除了目标胞腔 $e_\beta^{k-1}$ 以外的所有部分“捏成一个点”（商掉 $X_{k-2}$），得到一个球面 $S^{k-1}_\beta$。计算这个从球面到球面的映射的度数。
**第三步：写出边界矩阵**
将第二步计算出的所有 $d_{\alpha\beta}$ 组成一个矩阵。矩阵的列对应 $k$ 维胞腔，行对应 $(k-1)$ 维胞腔。
**第四步：代数求解同调群**
利用公式 $H_k(X) \cong \ker(d_k) / \operatorname{Im}(d_{k+1})$ 求解最终结果。
- _操作_：求出 $d_k$ 矩阵的零空间（核 $\ker$），再求出 $d_{k+1}$ 矩阵的列空间（像 $\operatorname{Im}$），最后做商群。这就完全变成了线性代数中求 Smith 标准型的问题。
### 考试注意事项与避坑指南
1. **引理直接用**：笔记中关于 $H_q(X_k) = 0$ ($q > k$) 以及包含映射诱导同构等引理（Lemma 4.8.1），主要是为了证明“胞腔同调群等于拓扑同调群”。考试计算时，**不需要**重新证明，直接默认空间的同调群可以通过上述“四步走”的胞腔链复形算出来即可。
2. **Degree (度) 的符号极其重要**：计算缠绕圈数时，必须考虑**方向**。顺时针包绕和逆时针包绕的度数是互为相反数的。很多计算错误都出在正负号上。
3. **两端情况**：
    - 最高维度 $n$ 的同调群，因为没有更高维的胞腔，$d_{n+1}$ 是零映射，所以 $\operatorname{Im}(d_{n+1}) = 0$，$H_n(X) = \ker(d_n)$。
    - 第 0 维同调群，因为 $d_0$ 是零映射，$\ker(d_0) = C_0$，所以 $H_0(X) = C_0 / \operatorname{Im}(d_1)$。
