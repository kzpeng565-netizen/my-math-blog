**user**: 你老师黑板上的这套板书，展示的是处理圆盘上泊松方程（Poisson Equation）最标准、最强大的通用解法：**傅里叶级数展开法（分离变量法的推广）**。

当方程右端项（非齐次项）不是零，且区域是圆盘时，核心思路是**将右端项转换到极坐标下，并对其进行角向（$\theta$）的傅里叶展开，进而把偏微分方程转化为一系列关于径向（$r$）的常微分方程（欧拉方程）**。

下面为你梳理出这道题严丝合缝的标准解答过程。

---

### 第一步：将右端项转换到极坐标并做傅里叶展开

原方程为 $\Delta u = x^2 y$。
令 $x = r\cos\theta$，$y = r\sin\theta$，将右端项化为极坐标：


$$x^2 y = (r\cos\theta)^2(r\sin\theta) = r^3 \cos^2\theta \sin\theta$$

为了利用分离变量的思想，我们需要把角度部分化为标准的一次三角函数（即傅里叶级数的形式）。利用降幂公式和积化和差公式：


$$r^3 \cos^2\theta \sin\theta = r^3 \left( \frac{1+\cos 2\theta}{2} \right) \sin\theta = \frac{r^3}{2} (\sin\theta + \cos 2\theta \sin\theta)$$


因为 $\cos 2\theta \sin\theta = \frac{1}{2}(\sin 3\theta - \sin\theta)$，代入上式得到：


$$x^2 y = \frac{r^3}{2} \left( \sin\theta + \frac{1}{2}\sin 3\theta - \frac{1}{2}\sin\theta \right) = \frac{r^3}{4}\sin\theta + \frac{r^3}{4}\sin 3\theta$$

### 第二步：假设解的形式并导出常微分方程

既然右端项只包含 $\sin\theta$ 和 $\sin 3\theta$ 两项，根据叠加原理和傅里叶级数的正交性，解 $u(r,\theta)$ 必然也只包含这两项。
我们设解的形式为（这也是你老师黑板上 $\sum a_n(r)e^{in\theta}$ 在实数域的具体化）：


$$u(r,\theta) = R_1(r)\sin\theta + R_3(r)\sin 3\theta$$

极坐标下的拉普拉斯算子为 $\Delta u = u_{rr} + \frac{1}{r}u_r + \frac{1}{r^2}u_{\theta\theta}$。将假设的解代入方程 $\Delta u = \frac{r^3}{4}\sin\theta + \frac{r^3}{4}\sin 3\theta$：


$$\left( R_1'' + \frac{1}{r}R_1' - \frac{1}{r^2}R_1 \right)\sin\theta + \left( R_3'' + \frac{1}{r}R_3' - \frac{9}{r^2}R_3 \right)\sin 3\theta = \frac{r^3}{4}\sin\theta + \frac{r^3}{4}\sin 3\theta$$

对比两边对应项的系数，我们将 PDE 成功降维成了两个独立的非齐次欧拉方程：

1. **对应 $\sin\theta$ 的径向方程：** $r^2 R_1'' + r R_1' - R_1 = \frac{r^5}{4}$
2. **对应 $\sin 3\theta$ 的径向方程：** $r^2 R_3'' + r R_3' - 9R_3 = \frac{r^5}{4}$

同时，根据边界条件 $u|_{r=a} = 0$，有 $R_1(a) = 0$ 且 $R_3(a) = 0$。

### 第三步：求解常微分方程

**1. 求解 $R_1(r)$：**

* **齐次通解：** 对应齐次方程 $r^2 R_1'' + r R_1' - R_1 = 0$ 的特征根为 $\pm 1$。通解为 $C_1 r + D_1 r^{-1}$。为保证在圆心 $r=0$ 处解析（有界），必须丢弃 $r^{-1}$ 项，故齐次解为 $C_1 r$。
* **特解：** 设特解为 $A r^5$。代入方程：$r^2(20A r^3) + r(5A r^4) - A r^5 = 24A r^5 = \frac{r^5}{4}$，解得 $A = \frac{1}{96}$。
* **确定常数：** $R_1(r) = C_1 r + \frac{r^5}{96}$。代入边界条件 $R_1(a) = 0$，得 $C_1 a + \frac{a^5}{96} = 0 \implies C_1 = -\frac{a^4}{96}$。
* **结果：** 
$$R_1(r) = \frac{1}{96}(r^5 - a^4 r)$$



**2. 求解 $R_3(r)$：**

* **齐次通解：** 特征根为 $\pm 3$。同理丢弃奇点项，齐次解为 $C_3 r^3$。
* **特解：** 设特解为 $B r^5$。代入方程：$r^2(20B r^3) + r(5B r^4) - 9B r^5 = 16B r^5 = \frac{r^5}{4}$，解得 $B = \frac{1}{64}$。
* **确定常数：** $R_3(r) = C_3 r^3 + \frac{r^5}{64}$。代入边界条件 $R_3(a) = 0$，得 $C_3 a^3 + \frac{a^5}{64} = 0 \implies C_3 = -\frac{a^2}{64}$。
* **结果：** 
$$R_3(r) = \frac{1}{64}(r^5 - a^2 r^3)$$



### 第四步：写出最终解并转回直角坐标

将算出的径向函数代回原假设，极坐标下的解为：


$$u(r,\theta) = \frac{1}{96}(r^5 - a^4 r)\sin\theta + \frac{1}{64}(r^5 - a^2 r^3)\sin 3\theta$$

为了展现顶级的代数功底，我们可以将其完美地转回直角坐标系（因为原题是在直角坐标系下给出的）：

* 第一项提取 $r^4$：$\frac{1}{96}(r^4 - a^4)(r\sin\theta) = \frac{1}{96}((x^2+y^2)^2 - a^4)y$
* 第二项利用三角恒等式 $\sin 3\theta = 3\sin\theta - 4\sin^3\theta$：
$r^3\sin 3\theta = 3r^2(r\sin\theta) - 4(r\sin\theta)^3 = 3(x^2+y^2)y - 4y^3 = 3x^2y - y^3$
所以：$\frac{1}{64}(r^2 - a^2)(r^3\sin 3\theta) = \frac{1}{64}(x^2+y^2 - a^2)(3x^2y - y^3)$

**最终完美的直角坐标解为：**


$$u(x,y) = \frac{y}{96}\big((x^2+y^2)^2 - a^4\big) + \frac{3x^2y - y^3}{64}\big(x^2+y^2 - a^2\big)$$
