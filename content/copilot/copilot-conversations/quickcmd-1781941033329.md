**ai**: **第一部分：二维上半平面的傅里叶变换法**  

对于上半平面 $\mathbb{H}^+ = \{(x, y) \mid y > 0\}$，问题在无界区域上。处理无界直线 $x \in \mathbb{R}$，最锐利的工具是**傅里叶变换**。  

1. **问题重述与变量替换**  
   狄利克雷问题：  
   $$u_{xx} + u_{yy} = 0 \quad (\text{在 } \mathbb{H}^+ \text{ 内})$$  
   $$u(x, 0) = g(x) \quad (x \in \mathbb{R})$$  
   为贴近直觉，把 $y$ 看作“时间” $t$（$t>0$），方程改写为 $u_{tt} + u_{xx} = 0$。  

2. **核心操作：对 $x$ 做傅里叶变换**  
   设 $\hat{u}(\xi, t)$ 是 $u(x,t)$ 关于 $x$ 的傅里叶变换。由导数性质，$\partial_x$ 变为 $i\xi$，故 $u_{xx}$ 变为 $(i\xi)^2\hat{u} = -|\xi|^2\hat{u}$。PDE 降为关于 $t$ 的 ODE：  
   $$\hat{u}_{tt}(\xi, t) - |\xi|^2\hat{u}(\xi, t) = 0$$  

3. **求解 ODE 并舍弃发散项**  
   特征方程 $\lambda^2 - |\xi|^2 = 0$，通解为：  
   $$\hat{u}(\xi, t) = a(\xi)e^{-|\xi|t} + b(\xi)e^{|\xi|t}$$  
   当 $t \to +\infty$ 时，物理量不能发散，故 $b(\xi)=0$。得：  
   $$\hat{u}(\xi, t) = a(\xi)e^{-|\xi|t}$$  
   在边界 $t=0$ 处，$\hat{u}(\xi,0)=a(\xi)$，由边界条件 $u(x,0)=g(x)$ 得 $a(\xi)=\hat{g}(\xi)$。最终频域解：  
   $$\hat{u}(\xi, t) = \hat{g}(\xi)e^{-|\xi|t}$$  

4. **逆变换与卷积定理（推导泊松核）**  
   傅里叶逆变换回到时空域：  
   $$u(x, t) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} \hat{g}(\xi)e^{-|\xi|t} e^{i\xi x} d\xi$$  
   代入 $\hat{g}(\xi)=\frac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} g(z)e^{-i\xi z}dz$ 并交换积分顺序：  
   $$u(x, t) = \int_{-\infty}^{\infty} g(z) \left[ \frac{1}{2\pi} \int_{-\infty}^{\infty} e^{-|\xi|t} e^{i\xi(x-z)} d\xi \right] dz$$  
   计算方括号内积分：拆成 $(-\infty,0)$ 和 $(0,\infty)$：  
   $$\int_0^\infty e^{-\xi(t - i(x-z))} d\xi + \int_{-\infty}^0 e^{\xi(t + i(x-z))} d\xi = \frac{1}{t - i(x-z)} + \frac{1}{t + i(x-z)}$$  
   通分得 $\frac{2t}{t^2 + (x-z)^2}$，乘以 $\frac{1}{2\pi}$ 得泊松核：  
   $$K(x,z,t) = \frac{t}{\pi(t^2 + (x-z)^2)}$$  
   将 $t$ 换回 $y$，得到：  
   $$u(x,y) = \frac{y}{\pi} \int_{-\infty}^{\infty} \frac{g(z)}{(x-z)^2 + y^2} dz$$  
   这与几何方法结果一致。
