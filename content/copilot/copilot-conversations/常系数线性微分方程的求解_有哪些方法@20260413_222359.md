### 1. 特征根法（用于齐次方程）
- **适用对象**：齐次线性微分方程 $y^{(n)} + a_1 y^{(n-1)} + \dots + a_n y = 0$，其中系数 $a_i$ 为常数。
- **核心步骤**：
    1. 写出特征方程 $\lambda^n + a_1 \lambda^{n-1} + \dots + a_n = 0$。
    2. 根据特征根的类别（实单根、复根、重根）写出对应的基本解组。
    3. 通解为基本解组的线性组合。

### 2. 待定系数法（用于非齐次方程，右端项为特定形式）
- **适用对象**：非齐次方程 $L[y] = f(x)$，其中 $f(x)$ 为多项式、指数函数 $e^{\alpha x}$、正弦/余弦函数 $\sin \beta x, \cos \beta x$ 或它们的乘积和线性组合。
- **核心思想**：根据 $f(x)$ 的形式和特征根的情况，预先设定一个形式特定的特解（包含待定系数），代入原方程确定这些系数。
- **关键点**：需要注意特解形式是否与齐次解“冲突”（即 $f(x)$ 的指数或三角部分是否为特征根），若冲突则需乘以 $x^k$。

### 3. 常数变易法（用于非齐次方程，通用方法）
- **适用对象**：非齐次方程 $L[y] = f(x)$，对 $f(x)$ 的形式无特殊要求。
- **核心思想**：已知齐次方程的通解 $y_h = C_1 y_1(x) + \dots + C_n y_n(x)$，将常数 $C_i$ 变易为函数 $u_i(x)$，设特解 $y_p = u_1(x) y_1(x) + \dots + u_n(x) y_n(x)$。
- **核心步骤**：通过求解关于 $u_i'(x)$ 的线性代数方程组（如您笔记中定理6.3*的推导所示），积分得到 $u_i(x)$。这是最通用的方法，但计算量可能较大。

### 4. 拉普拉斯变换法（特别适用于初值问题）
- **适用对象**：带有初始条件的线性微分方程。
- **核心思想**：利用拉普拉斯变换将微分方程转化为关于象函数的代数方程，求解代数方程后再进行逆变换得到原微分方程的解。
- **优点**：能系统性地处理初值条件，尤其适用于右端项不连续或为分段函数的情况。

### 核心原则与步骤

1.  **“照猫画虎”**：根据 $f(x)$ 的**类型**，设定对应形式的特解。
2.  **“避开齐次”**：检查你设定的特解中，**指数函数部分的指数 $\alpha$ 或三角函数部分的频率 $\beta$ 是否为齐次方程的特征根**。如果是，就需要乘以 $x^k$，其中 $k$ 是该特征根的重数。

### 常见形式与设定规则（对照表）

| 非齐次项 $f(x)$ 的形式 | 初次设定的特解 $y_p$ 形式 | 关键检查与调整规则 |
| :--- | :--- | :--- |
| **$P_m(x)$** <br>（m 次多项式） | $Q_m(x)$ <br>（一个完整的 m 次多项式，所有项都要） | 检查 **0** 是否为特征根。如果不是，直接使用；如果是 k 重根，则乘以 **$x^k$**。 |
| **$e^{\alpha x} P_m(x)$** | $e^{\alpha x} Q_m(x)$ | 检查 **$\alpha$** 是否为特征根。如果不是，直接使用；如果是 k 重根，则乘以 **$x^k$**。 |
| **$e^{\alpha x} [P_m(x)\cos\beta x + P_l(x)\sin\beta x]$** | $e^{\alpha x} [Q_n(x)\cos\beta x + R_n(x)\sin\beta x]$ <br>其中 $n = \max(m, l)$ | 检查 **$\alpha \pm i\beta$** 是否为特征根。如果不是，直接使用；如果是 k 重根，则乘以 **$x^k$**。 |
| **$\cos\beta x$ 或 $\sin\beta x$** <br>（即上式中 $\alpha=0, P_m$ 为常数） | $A\cos\beta x + B\sin\beta x$ | 检查 **$\pm i\beta$** 是否为特征根。如果不是，直接使用；如果是 k 重根，则乘以 **$x^k$**。 |
