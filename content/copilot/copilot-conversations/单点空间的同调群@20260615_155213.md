## 1. 奇异链群 $C_k$
奇异 $k$‑单形是连续映射 $\sigma: \Delta^k \to \{*\}$。对于 $k\ge 1$，标准单形 $\Delta^k$ 的维数 $k\ge 1$，但像空间 $\{*\}$ 的维数为 $0$。这样的映射**必定是常值映射**，且因为 $\dim(\text{像}) = 0 < k$，所以它是**退化**奇异单形。

在定义奇异链复形时，我们通常令 **退化的奇异单形生成的链为零**（或者商掉退化部分，视其为 $0$）。因此所有 $k$‑维退化单形在 $C_k$ 中都是 $0$。于是：
$$C_k = 0 \quad (\forall k \ge 1).$$

## 2. 闭链群 $Z_k$
闭链群定义为 $Z_k = \ker(\partial_k: C_k \to C_{k-1})$。因为 $C_k = 0$，其核当然也是零：
$$Z_k = 0 \quad (\forall k \ge 1).$$

## 3. 边缘链群 $B_k$

$$B_k = 0 \quad (\forall k \ge 1).$$

## 4. 同调群 $H_k$
$$H_k = Z_k / B_k = 0/0 = 0 \quad (\forall k \ge 1).$$
