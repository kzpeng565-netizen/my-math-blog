**ai**: **分析对称性与化简边界条件**  
给定 $\Delta u=0$，边界条件 $\left.u\right|_{r=1} = 3\cos 2\theta+1$ 与方位角 $\varphi$ 无关。球体内部的解是轴对称的，即 $u = u(r,\theta)$。利用二倍角公式化简边界条件：  
$$g(\theta) = 3(2\cos^2\theta-1)+1 = 6\cos^2\theta-2$$

**写出球坐标拉普拉斯方程并分离变量**  
轴对称球坐标拉普拉斯方程为：  
$$u_{rr} + \frac{2}{r}u_r + \frac{1}{r^2}(u_{\theta\theta} + \cot\theta u_\theta) = 0$$  
令 $u(r,\theta) = R(r)\Theta(\theta)$，代入后分离变量得：  
$$\frac{r^2 R'' + 2r R'}{R} = -\frac{\Theta'' + \cot\theta \Theta'}{\Theta} = \lambda$$  
得到两个常微分方程：  

1. **角向方程：** $\Theta'' + \cot\theta \Theta' + \lambda\Theta = 0$  
2. **径向方程：** $r^2 R'' + 2r R' - \lambda R = 0$

**求解角向方程（导出勒让德多项式）**  
令 $x = \cos\theta$，则 $\theta \in [0,\pi]$ 对应 $x \in [-1,1]$。角向方程化为勒让德微分方程：  
$$(1-x^2)\frac{d^2\Theta}{dx^2} - 2x\frac{d\Theta}{dx} + \lambda\Theta = 0$$  
为保证 $x=\pm 1$ 处有界，本征值 $\lambda = n(n+1)$，$n=0,1,2,\dots$。本征函数为勒让德多项式 $P_n(x)$，即 $\Theta_n(\theta) = P_n(\cos\theta)$。

**求解径向方程并舍弃奇性项**  
将 $\lambda = n(n+1)$ 代入径向方程：  
$$r^2 R'' + 2r R' - n(n+1)R = 0$$  
这是欧拉方程，设 $R(r)=r^\alpha$，得特征方程 $\alpha(\alpha-1)+2\alpha - n(n+1)=0$，解得 $\alpha=n$ 或 $\alpha=-(n+1)$。通解为：  
$$R_n(r) = A_n r^n + B_n r^{-(n+1)}$$  
由于区域包含 $r=0$，为保证球心处解析，取 $B_n=0$，所以 $R_n(r)=A_n r^n$。

**级数叠加与系数匹配**

$$u(r,\theta) = \sum_{n=0}^{\infty} C_n r^n P_n(\cos\theta)$$

$$u(1,\theta) = \sum_{n=0}^{\infty} C_n P_n(\cos\theta) = 6\cos^2\theta-2$$

$$6\cos^2\theta-2 = 2(3\cos^2\theta-1) = 4P_2(\cos\theta)$$
