# DECISIONS

<!-- ai_provenance: source=codex; date=2026-08-23; verification=user-confirmed -->

## D-001 独立命名

- 决定：插件使用新名称 MathInk Forge，插件 ID 使用 `mathink-forge`。
- 原因：与上游 InkedMark Advanced 清楚区分，避免安装、启用和排障时混淆。

## D-002 固定上游基线

- 决定：以提交 `25515b65ce0ea9de47271f9b41c7c55cbc2605fa` 为可追溯上游基线，开发分支为 `codex/v1.0`。
- 原因：当前源码有大量未提交改动，必须保留明确参照点。

## D-003 性能问题采用先回退、后定位

- 决定：已将平板回退到旧构建；完成旧版基线和单变量 A/B 前，不继续叠加性能修复。
- 原因：一次修改 HUD、纸张布局、事件顺序和导出逻辑会破坏因果判断。

## D-004 设备实测优先级高于桌面模拟

- 决定：自动化测试用于防回归，M-Pencil 的跟笔、断笔和丢笔结论以平板实测为准。
- 原因：Pointer Events、WebView、触控笔固件和渲染调度具有设备相关性。

## D-005 导出成功必须有文件证据

- 决定：导出验收需要实际文件路径、非零大小、可解析内容和 SHA-256；仅出现成功提示不算通过。
- 原因：已经出现用户执行导出但目录中没有 JSON 的情况。

## D-006 回退版与调查版分开保存

- 决定：实际部署制品放在 `artifacts/deployed-rollback/`，未确认构建放在 `artifacts/unconfirmed-current/`。
- 原因：避免误部署和错误发布。

## D-007 不保存用户正文

- 决定：项目交接只保留笔画统计、版本号、哈希和脱敏结论，不复制用户的原始手写笔记正文。
- 原因：缩小隐私暴露范围，同时保留足够的调试证据。

## D-008 v1.0 发布门槛

- 决定：v1.0 至少需要通过核心自动化测试、桌面基本功能、平板快速书写、保存重开、撤销重做和真实导出验证。
- 原因：安装成功或单次书写正常不足以证明版本可用。
