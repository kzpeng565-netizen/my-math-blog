## 1. 本次升级

### 课程策略

- 本学期课程严格为概率论、泛函分析和微分几何；
- 删除课程首周预设“基线检索练习”；

## 2. MathInk 适配

参考 `D:\MathInk-Forge-Project` 的序列化与识别边界：

- 正文始终是普通 Markdown；
- 忠实识别文字位于 `<!--inkedmark-text-->` 管理段，可按页包含 `<!--inkedmark-page:N-->`；
- 画布图片投影为 `![alt](<relative-path>)`，相邻 `mathink:image` 只保存位置和尺寸；
- 压缩笔迹保存在 `%%inkedmark ... %%` 或 fenced block。

导出器 v6 的处理：

| 内容 | 处理 |
|---|---|
| 普通文字、标题、LaTeX | 保留并进入 FTS |
| MathInk 忠实识别文字 | 保留 |
| 标准相对图片引用 | 保留引用 |
| 图片二进制 | 不导出 |
| `mathink:image` 坐标元数据 | 删除 |
| 压缩笔迹、base64 | 删除并替换为手写占位符 |
| `.ink.md`、冲突文件、隐藏目录 | 不进入目录递归 |

- 通过 SQLite backup API 创建的 `goal-agent.sqlite3`；

恢复顺序：

1. 备份当前 v2 SQLite；
2. 优先逐文件恢复代码、配置或 unit；
3. `systemctl daemon-reload`；
4. 只重启 `activitywatch-advisor-web.service` 和 `focus-garden.service`；
5. 只有数据库损坏且明确接受丢失新反馈时，才恢复备份 SQLite；
6. 普通计划回退应使用页面的 plan version 1，而不是覆盖数据库文件。

## 6. 用户接下来怎么用

1. 打开 Focus Garden → 目标模式 → 证据与资料；
2. 证据类型选择“实际授课小节与掌握度”；
3. 课程选择“微分几何”；
4. 根据 `1.1.md` 勾选第一节课实际讲到的小节；
5. 每个小节填写 0–3 掌握度；
6. 可填习题数、证明复述、深度分钟和阻塞；
7. 提交后检查本周两项微分几何任务是否变为具体章节任务；
8. 只有任务显示“可安排”后，再确认推荐日期。
