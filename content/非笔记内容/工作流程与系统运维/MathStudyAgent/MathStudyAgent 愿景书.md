
你现在这套思路里，最有价值的其实不是“多 Agent”或者“LangGraph”，而是这几个东西组合起来了：

- **教材作为唯一事实来源**：减少模型乱讲、跑题。
    
- **强模型只负责真正的数学判断**：证明、反例、概念理解、错误诊断。
    
- **保存学习状态**：知道你已经学到哪里、哪些地方卡过。
    
- **不同任务采用不同 prompt**：导读、证明提示、习题、例子分析不是同一种任务。
    
- **允许拒答和降级**：不知道就不要硬解释。
    

如果这些东西调好，它完全可能达到一种状态：

> 你打开某一节，它已经知道这一节在整本书里的作用；  
> 你读到一个证明卡住，它不会马上给答案，而是准确指出当前真正缺的一步；  
> 你提出一个错误理解，它能够识别这是你过去反复出现的问题；  
> 学完以后，它能从教材里选出最值得做的三道题，而不是机械地随机出题。

这种系统对自学会非常 useful。

但我认为你要避免一个误区：**不要追求 Agent 看起来越来越复杂，而要追求每一次交互越来越准。**



所以我对它的现实预期大概是：

**第一阶段：比直接 ChatGPT 好用。**

做到：

- 自动拿对教材上下文；
    
- 不需要每次解释自己学到哪里；
    
- prompt 稳定；
    
- 不乱剧透答案。
    

这个其实比较容易达到。

**第二阶段：成为真正 useful 的私人导师。**

做到：

- 能诊断误解；
    
- 动态控制提示；
    
- 根据过去学习历史调整讲解；
    
- 自动选择复习和习题。
    

这个需要大量调试，但我认为完全可行。

**第三阶段：接近优秀真人导师。**

最困难，因为它需要非常准确地建模：

> “你现在脑子里究竟是怎么理解这个概念的？”

这个可能需要长期积累交互数据、设计 learner model，再加比较好的数学模型。

但即使只做到第二阶段，对你而言已经很有价值。

而且我现在越来越觉得，你这个项目最值得研究的并不是“怎么调用 GPT”，而是：

> **如何把一个通用强数学模型，变成一个能够长期跟踪学习者状态、控制提示和教材范围的数学导师。**

这实际上就是一个相当明确的 AI for Math / AI for Education 问题。

所以我会建议你接下来**停止继续堆架构一段时间**，拿现在的版本真实学习 1–2 个章节。每一次出现“这回答真蠢”“这里特别好用”“它为什么没有意识到我卡在这里”，都记录下来。

20～50 个这样的真实失败案例，比你再设计十个模块更有价值。

你最后很可能发现，真正让 Agent 从“能用”变成“非常 useful”的，不是某个新模型，而是**几十个针对真实失败案例做出来的小设计。**

目前 Agent 工程越来越明确的经验是：**先把单一 workflow 做准，再增加复杂 orchestration。** OpenAI 自己的 agent engineering guide 也建议优先使用简单、可组合的 prompt/tool 结构，只有在实际任务确实要求时才引入 multi-agent；2026 年的 agent improvement 工作流更强调 `真实 traces → 人类反馈 → evals → 修改系统 → 再测`。


## 两周只攻 4 个能力

甚至把你原来的很多功能暂时砍掉，只留下：

### ① 教材上下文

你问某个问题时，它自动知道：

`当前章节 → 当前定义/定理 → 前置内容 → 后续一点点内容`

你不需要复制粘贴教材。

这是最基础的 UX 优势。

### ② 提示而不是答案

例如一道证明题：

`理解题意 → 让你尝试 → 极小提示 → 检查尝试 → 第二提示 → 完整证明`

这很可能比“更换成一个更强模型”更影响学习质量。苏格拉底式数学 tutoring 本身已经有专门研究，目标正是避免模型直接把 solution dump 给学生。

### ③ 一个很小的 learner model

先别搞什么几十维状态。

每个重要概念只记录：

`未接触 / 初步理解 / 能使用 / 容易犯错 / 熟练`

再额外存：

`最近一次典型错误`

已经足够产生非常大的个性化空间。

### ④ 错误案例库 + eval

这是最重要的工程部分。

每次你觉得：

> “这个回答很蠢。”

按一下 👎，把：

`问题 + 教材上下文 + Agent回答 + 你认为的问题`

存下来。

积累到 30 条以后，这些东西就是你自己的 **MathTutorBench**。

以后你换：

- GPT-5.5 High
- GPT-5.6 Sol
- 新 prompt
- 新 retrieval
- 新 learner model
