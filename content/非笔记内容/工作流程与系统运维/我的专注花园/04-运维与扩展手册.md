## 备份与恢复

Pi 权威存档与电脑镜像：

```text
/home/conrad/services/focus-garden/data/focus-garden.sqlite3
D:\MyFocusGardenArchive\focus-garden.sqlite3
```

`focus-garden-backup.timer` 每分钟调用 SQLite backup API 生成一致性快照到 `/home/conrad/workspace/focus-garden-archive/`。Syncthing 中 Pi 文件夹为 send-only，Windows 为 receive-only；不要改成双向同步活跃 SQLite。受版权保护的素材不在同步目录中。

恢复步骤：

1. 停止 Pi 的 `focus-garden.service`；
2. 备份当前损坏或错误版本，不要直接覆盖唯一副本；
3. 从电脑镜像或其 `.stversions` 恢复数据库到 Pi 权威路径；
4. 启动后检查 `/api/health`、奖励数量、花园尺寸和植物显示；
5. 运行测试，但不要让测试指向恢复后的正式数据库。

## 常见故障

### 页面打不开

- 确认手机或电脑 Tailscale 已连接；
- 检查 `focus-garden.service`、`127.0.0.1:8838` 和 `tailscale serve status`；
- 确认 8460 仍标记为 `tailnet only`；
- 不要用 Funnel 解决访问问题。

### 系统状态读取失败（Unexpected end of JSON input）

==若“系统状态”提示 JSON 解析失败，通常是 `/api/system-status` 在组装 Windows bridge 时异常断连。先在 Pi 执行 `curl -fsS http://127.0.0.1:8838/api/system-status`，再查 `journalctl -u focus-garden.service -n 100` 中的 `active_locks` traceback；2026-08-06 已修复列表/字典两种格式，接口返回 200 后刷新页面即可。==

### 进入页面提示 Cannot set properties of null (setting 'textContent')

==这是自动“同步奖励”引用了已删除的 `#piStatus` 元素所致；2026-08-06 已移除残留引用。若仍看到旧提示，请强制刷新页面（Ctrl+F5）获取带版本号的 `app.js`。==

### 同步奖励失败

```bash
systemctl status focus-garden.service --no-pager
journalctl -u focus-garden.service --no-pager -n 100
curl -fsS -X POST -H 'Content-Type: application/json' -d '{}' \
  http://127.0.0.1:8838/api/rewards/sync
```

Pi 正式服务设置 `FOCUS_GARDEN_PI_LOCAL=1`，直接读取 `/home/conrad/workspace/activitywatch-advisor`，不再 SSH 回自己。若失败，检查服务日志、目录是否存在、JSON 权限与数据格式。Windows 开发副本才需要检查 SSH 密钥和 `pi.local`。

### 显示“奖励不存在”

- 先刷新页面，确认奖励仍为 `pending`；
- 确认请求 URL 中带冒号的奖励 ID 已编码，服务端会 `unquote`；
- 若奖励已种植，重复请求会返回原种植记录；
- 若数据库中确实无该 ID，重新同步源事件，并检查稳定 ID 是否被规则改动。

### Windows 开发副本的 Cold Turkey 启动失败

- 检查 `D:\Cold Turkey\Cold Turkey Blocker.exe` 是否存在；
- 检查 `D:\tools\computer-intervention-agent\config.json` 的 `allowed_blocks`；
- profile 中每个 block 都必须在 allowlist 中；
- 不要直接写 Cold Turkey 内部 SQLite，也不要在不确定时用正式模式试错。

Pi 正式服务固定为安全模拟；从手机或 Pi 页面开始专注不会调用 Cold Turkey，因此不应按这一节排查 Pi。

### 植物或草方块不显示

- 检查 `config/plants.json` 中的 `sprite` 相对 `static/` 是否存在；
- 检查浏览器开发者工具的请求响应类型，缺失静态文件目前可能错误回退到 HTML；
- 确认 PNG 有透明背景并保留像素插值设置。

## 新增植物、树苗或蘑菇

1. 把透明 PNG 放在 `static/assets/` 的本机素材目录。
2. 在 `config/plants.json` 增加对象，至少提供稳定且唯一的 `id`、中文 `name`、`category`、`tier` 和相对 `static/` 的 `sprite`。
3. `category` 可使用 `flower`、`tree`、`mushroom` 或 `decoration`；种植弹窗只按 `tier: basic | advanced` 分为“初级”和“高级”，不再为蘑菇保留单独标签页。
4. 不要修改已经被种植记录引用的旧 `id`；替换贴图时只改 `sprite`。
5. 增加缺图和重复 ID 测试，再检查小屏幕与大花园缩放。

示例：

```json

  "id": "original_small_mushroom_01",
  "name": "小褐伞",
  "category": "mushroom",
```

## 新增奖励规则

在 `focus_garden/pi_sync.py` 中把源事实转成标准事件，并遵守：

- ID 必须由规则名和稳定源 ID 构成，重复同步保持完全相同；
- 只奖励已确认事实，不把模型猜测当事实；
- `reason` 说明为什么发奖；
- `payload` 保存必要审计字段，不保存密码、token 或大段原始日志；
- 为满足、排除、重复同步各写测试；
- 同步更新 [[01-数据来源与处理]]、`树莓派行为数据与接口索引.md`、`PROJECT_STATE.md`、`DECISIONS.md` 和 `NEXT_STEPS.md`。

## 新增专注模式

编辑 `config/focus_profiles.json`，新增稳定 `id`、名称、说明和 blocks。所有 blocks 必须已经存在于 computer-intervention-agent 的 allowlist。当前时长约束是 5—180 分钟；每 40 分钟奖励规则位于数据库结算代码，不在 profile 中。

| 现象 | 处理 |
|---|---|
| 页面 401 / 数据不显示 | 浏览器必须经花园 `:8460` 代理访问；直连 8767 会被拒（loopback + bridge header 缺一不可）。检查 `activitywatch-advisor-web.service` 与 `focus-garden.service`。 |

==当前应安装 `1.3.3 (18)`。系统状态应显示“新版状态协议 1.3.3”和“重复请求防护”；计数增加表示客户端成功拦截旧 pending，不表示锁机失败。同一 request 的运行日志最多出现三次“第 N/3 次尝试”，成功或失败上传后不得再次从第 1/3 次开始。==

==真实快速番茄通知可能带 `AUTO_CANCEL`；排障时应查看“捕获番茄计时通知候选”，不能恢复为排除全部 `AUTO_CANCEL`。Pi 端重复 final 应返回 `already_completed`，`computer_interventions/responses` 对同一 request 只保留一份业务回执。==

## 2026-08-09：任务日历检查与排障

==“当前待办”的今天分组应同时出现普通任务与 `scheduled_date=今天` 的循环任务。日历最近七天从今天起算 7 天；本月缩略格只显示任务数、预计番茄数与 `highest` 红点，点击后才显示当天逐项详情。底部只列 `status=active` 且未归档的近期动态，upcoming 不在这里展示。==

检查顺序：

```bash
curl -fsS http://127.0.0.1:8838/api/tasks
curl -fsS 'http://127.0.0.1:8838/api/recent-context?limit=8'
python3 -m unittest discover -s tests -v
```

==若清单缺少当天循环任务，先检查 `/api/tasks` 的 `recurring[].scheduled_date`，不要在前端猜测或直接改 Obsidian；若日历缺少 active 动态，检查近期动态对象的 `status/archived`。生产回滚目录为 `/home/conrad/services/focus-garden/backups/task-calendar-20260809-200247/`，只恢复三份静态文件，不覆盖 SQLite、task queue 或 recent-context 数据。==
