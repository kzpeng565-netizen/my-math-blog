## 一分钟接管

1. 在电脑或手机连接 Tailscale 后，打开 `https://pi.taild4d3f7.ts.net:8460/`；桌面快捷方式已指向该地址。
2. 若打不开，先检查手机 Tailscale 是否已连接，再在 Pi 检查 `focus-garden.service` 与 `tailscale serve status`。
3. Pi 端专注计时是安全模拟模式，不会替 Windows 调用 Cold Turkey；网页会明确提示这一点。
4. 权威存档只在 Pi 写入。不要用迁移前的 Windows 快捷方式同时启动旧本地实例。
5. 电脑镜像通常在一分钟左右更新；恢复时只复制 `D:\MyFocusGardenArchive\focus-garden.sqlite3`，不要反向启用 Syncthing 双向写入。

## 边界

- 这是私人 Tailnet 工具；专注花园不得启用 Tailscale Funnel，也不得把 8838 改绑 `0.0.0.0`。
- 不要把树莓派密码、Next Action 登录信息、token 或 Cold Turkey 内部数据库写入本文件夹。
- 当前包含来自本机游戏安装的贴图和用户提供的草方块，仅限个人私有使用。它们只随 SSH 私有迁移进入 Pi，不进入 Syncthing 存档目录。
- 本文件夹是交接入口；运行真相以 Pi 的服务、代码和 SQLite 为准，`D:\MyFocusGarden` 保留为开发与恢复副本。
