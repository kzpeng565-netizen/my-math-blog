## 1. 已上线行为

Goal 模式“证据与资料”已从通用长表改为按任务类型生成的快速表单。本周任务卡新增“记进度”，课程卡新增“记录上课”；也可以不关联具体任务，手动选择记录类型。

当前支持：

- 实际授课与逐小节掌握度；
- 章节练习 / 抽代书面题；
- 定义复述 / 证明重建；
- 课程正式成绩、自评或估分；
- 数学所限时真题；
- 阅读 / 笔记、讲解；
- 抽代口头模拟；
- 受阻与调整请求。

表单只提交该类型的白名单字段。未填值保持 `null` 或缺失，不转换为 0；任务、轨道和课程尽量从当前任务带入。切换类型会重建表单，旧类型的输入不会进入新事件。

## 2. 可靠判断需要的条件

快速表单不把少量结果字段当作完整能力结论，而是把四类信息分开：任务上下文、本次实际表现、已授权材料、历史可比记录。

### 做题与证明

- 最终正确数和独立正确数分开；
- 记录提示、解答、混合帮助或未记录；
- 记录对照解答、他人核对、自我判断或未核对；
- 证明另存首次尝试、即时重做、隔日复测或未知；
- 数量约束为“独立正确 ≤ 最终正确 ≤ 尝试数”。

抽代书面题必须填写题组来源。只有无帮助且由解答/他人核对的记录才可能进入连续书面达标；同一题组重复使用不会形成不同题源证据。

### 课程成绩

考核项目直接读取课程档案中的期中、期末、作业、思考题或平时比例，并把确认权重写入事件。只有“老师 / 教务公布”的成绩进入总评情景；自评或估分保留原始事实，但不冒充正式成绩。权重缺失时总评继续显示未知。

### 限时真题

每次同时记录：题源 ID、得分/满分、实际用时、是否独立、是否完整限时、是否首次见题、评分依据。只有独立、新题、完整限时且由参考答案或他人核对的记录，才计入“不同真实题源连续达标”。缺任一条件都会保存，但不会满足硬指标。

### 授课进度

课程记录保存实际讲到的小节、0–3 掌握度，以及掌握度依据：听课感受、合书回忆、题目/证明检验或暂不评估。听课自评不会被解释为独立掌握；后续仍需成果和复测。

## 3. Agent 如何使用

每个 v2 事件保存 `feedback_schema_version=2`、`feedback_kind`、`performance`、`conditions`、备注和证据边界。状态 API 同时提供最近结构化证据。完整复盘会从最近五条证据的课程、考核项目、证明对象、题源和备注构造查询，只检索已授权材料索引，最多附带六条相关片段。

模型仍不能自行把材料片段、自评或单次成功升级成正式认证。确定性指标先检查来源、辅助、限时、新颖度和评分条件；材料或条件不足时保持未知。模型修改仍受原有 plan version、ApprovalRequest 和 task-sync 边界约束。

## 4. 25 秒目标

页面通过可直接点击的选项、任务上下文自动带入和最多一个条件追问减少输入。`<25 秒` 是真实用户测试标准，不是本次自动化验收已经证明的事实。

计时从点击任务卡“记进度”开始，到点击“保存本次反馈”为止，必须包含阅读、选择小节和纠错。电脑、手机和平板的每种常用类型至少各测三次；任何一次超过 25 秒就继续精简该类型。资料建档、长说明和新的数学检验不计作快速表单必填项，也不能被藏到计时之外后声称达标。

## 7. 下一次真实使用

1. 打开“目标模式 → 证据与资料”；
2. 从微分几何课程卡点“记录上课”；
3. 勾选真实讲到的小节；
4. 点共同掌握度，再选择“听课感受 / 合书回忆 / 题目或证明检验 / 暂不评估”；
5. 保存后阅读“这次证据能支持什么、仍不能判断什么”；
6. 检查对应本周课程任务是否变为具体章节并显示“可安排”；
7. 单独计时并记录是否低于 25 秒。
