## 4. 进度反馈输入

页面已经提供以下字段，允许只填当前确实知道的部分：

| 字段 | 用途 |
|---|---|
| 轨道、计划项 | 将证据归因到目标和具体周任务 |
| 证据类型 | 学习、练习、成绩、资料变化、困难或计划变化 |
| 深度学习分钟 | 计算真实吞吐量，只累计符合定义的深度学习 |
| 状态、完成量 | 判断周承诺执行情况 |
| 得分、满分、题源 ID | 课程情景、笔试和抽代真实题组验收 |
| 课程与考核权重 | 更新课程总评情景 |
| 困难度、信心 | 作为策略证据，不当作客观掌握度 |
| 阻塞原因 | 决定拆分、换序、补资料或降低短期负荷 |
| 变化说明 | 新课程要求、考试日期、题源失效等即时重算触发 |

示例：

```text
轨道：数学所笔试
题源 ID：AMSS-真实卷-B
深度学习：150 分钟
得分：116 / 150
困难度：4 / 5
信心：2 / 5
阻塞：高等代数计算速度慢，最后两题未完成
变化：无
```
