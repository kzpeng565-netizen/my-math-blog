## 1. 当前状态

微信视频陪伴提醒工具已经在 Windows 本地完成部署。后台守卫保持单实例运行，并已注册为当前用户登录启动项。2026-08-02 检查时，守卫进程为 1 个，状态为 `idle`，没有摄像头识别错误。

工具只负责微信视频通话中的陪伴提醒和可选娱乐封锁，不依赖树莓派、ActivityWatch、DeepSeek、ntfy 或 PushPlus，也不改写 Obsidian Tasks。

当前已经完成：

- 精确识别微信摄像头占用；
- 明确排除腾讯会议；
- 通话开始时弹出模式选择；
- 支持不提醒或按指定分钟间隔提醒；
- 支持 0.5 分钟，即每 30 秒提醒；
- 提醒包含置顶弹窗、声音和轮换内容；
- 支持通话开始时选择娱乐封锁；
- 支持从桌面控制页手动开启娱乐封锁；
- 适配当前 Windows 高 DPI，固定显示关键选项和底部按钮；
- 登录后自动启动。

## 3. 微信视频识别

### 3.1 数据源

工具每秒读取 Windows 当前用户的摄像头权限使用记录：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\CapabilityAccessManager\ConsentStore\webcam\NonPackaged
```

只有记录满足以下两个条件时，才认定微信视频正在进行：

1. 可执行文件名精确为 `Weixin.exe` 或 `WeChatAppEx.exe`；
2. `LastUsedTimeStart > 0` 且 `LastUsedTimeStop = 0`，表示摄像头仍在使用。

### 3.2 腾讯会议排除

`WeMeetApp.exe` 和 `WeMeet.exe` 被明确列入排除集合。即使腾讯会议正在使用摄像头，也不能触发微信陪伴模式。

识别不读取联系人姓名、窗口标题、聊天内容、摄像头画面或麦克风内容。

### 3.3 状态去抖

- 微信摄像头连续活跃 3 秒后，判定通话开始；
- 微信摄像头连续停止 10 秒后，判定通话结束；
- 一次通话只弹出一次模式选择窗口。

当前边界：如果微信视频通话中关闭了摄像头超过 10 秒，工具会认为本次通话已经结束。重新打开摄像头后，会作为新一次通话重新询问模式。

## 4. 通话开始时的模式选择

微信视频开始后，工具显示置顶选择窗口。当前选项为：

```text
不提醒
0.5 分钟（30 秒）
1 分钟
2 分钟
3 分钟
5 分钟
10 分钟
```

同时可以选择：

- 提醒时是否播放三音提示声；
- 是否立即开启 30 分钟娱乐封锁。

选择“不提醒”时仍然可以开启娱乐封锁。点击“本次不启用”或关闭窗口后，本次通话不提醒、不自动封锁，直到下一次微信视频开始才重新询问。

窗口已经改为按当前 DPI 和屏幕尺寸测量内容后自适应。提醒选项主体可以滚动，但娱乐封锁选项与“本次不启用 / 开始陪伴”按钮固定可见。

## 5. 提醒设计

到达选定间隔后，工具会：

1. 播放由三个音高组成的短提示声；
2. 显示置顶提醒弹窗；
3. 从预设内容中随机选择标题与正文；
4. 显示“2 秒后自动消失”；
5. 2 秒后自动关闭本次提醒，不需要点击确认。

当前提醒文案围绕以下内容轮换：

- 放下手里的其他事情；
- 看看对方此刻的表情；
- 注意对方的眼神和状态；
- 把注意力交还给这段安静陪伴。

提醒弹窗沿用 [[我的专注花园]] 的像素风视觉主题：`#dce9cd` 浅绿网格背景、`#fffdf3` 纸张色面板、`#15553f` 深绿粗边框、`#77c889` 薄荷色强调条、`#d9edb4` 浅绿状态标签和像素阴影。它不会读取或遮罩微信画面，也不会自动操作微信窗口。

## 6. 娱乐封锁

当前娱乐封锁复用两个已存在的 Cold Turkey block：

```text
常刷网站
bilibili
```

默认锁定时间为 30 分钟。开启方式有两种：

1. 微信视频开始时，在模式选择窗口勾选“现在开启娱乐封锁”；
2. 双击桌面上的 `微信陪伴模式控制台.vbs`，点击“开启 30 分钟”。

控制页的手动按钮会先显示确认提示，说明锁定期间通常不能提前解除。工具只允许调用 `config.json` 中预先配置的 block，不执行任意 Windows 命令，也不修改 Cold Turkey 内部数据库。

当前没有在开发验收中真实执行 30 分钟锁定，以免测试期间意外封锁网站。Cold Turkey 命令结构和 block 名已通过自动测试，第一次真实锁定仍需用户手动验收。

## 7. 启动、检查与停止

### 7.1 启动守卫

```powershell
& 'D:\tools\wechat-focus-guard\run-guard.ps1'
```

程序使用 Windows 单实例互斥量。重复运行启动脚本不会留下多个正式守卫。

### 7.2 打开控制页

```powershell
& 'D:\tools\wechat-focus-guard\run-control.ps1'
```

也可以直接双击桌面入口：

```text
微信陪伴模式控制台.vbs
```

控制页显示：

- 守卫是否正在运行；
- 当前是否识别到微信视频；
- 当前提醒模式和已提醒次数；
- 手动开启娱乐封锁按钮；
- 提醒弹窗和声音测试入口。

### 7.3 检查进程

```powershell
Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -eq 'pythonw.exe' -and
    $_.CommandLine -like '*wechat-focus-guard*focus_guard.py*'
  } |
  Select-Object ProcessId, CreationDate, CommandLine
```

### 7.4 停止守卫

```powershell
Get-CimInstance Win32_Process |
  Where-Object {
    $_.Name -eq 'pythonw.exe' -and
    $_.CommandLine -like '*wechat-focus-guard*focus_guard.py*'
  } |
  ForEach-Object { Stop-Process -Id $_.ProcessId }
```

## 8. 登录启动项

当前用户登录启动项：

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
名称：WeChatFocusGuard
```

它调用 `run-guard.ps1`，再由该脚本隐藏启动 `D:\anaconda\pythonw.exe`。不需要管理员权限。

如果需要取消登录自启动：

```powershell
Remove-ItemProperty `
  -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' `
  -Name 'WeChatFocusGuard'
```

取消启动项不会自动停止当前已经运行的守卫，需要另行执行停止命令。

工具不保存：

- 麦克风录音；
- 原 computer-intervention-agent 的密码；
- 任何树莓派 token、ntfy topic 或 API 密钥。

## 11. 常见排障

### 微信视频开始后没有弹窗

依次检查：

1. 后台守卫进程是否存在；
2. `state.json` 的 `updated_at` 是否持续更新；
3. `last_detection_error` 是否为空；
4. 微信是否确实开启摄像头；
5. 运行 `--test-detection` 查看当前识别结果；
6. 运行 `--test-mode` 确认 Tkinter 弹窗本身可以显示。

如果微信视频中关闭了摄像头，当前版本不会继续保持通话状态。

### 提醒没有声音

检查 Windows 系统音量、当前输出设备和应用音量。运行 `--test-reminder` 可以单独测试三音提示声。声音使用 Windows `winsound.Beep`，失败时回退到系统提示音。

### 窗口内容被裁切

当前版本已经使用内容测量、高 DPI awareness、滚动主体和固定底部区域。如果仍然裁切：

1. 记录 Windows 显示缩放比例；
2. 截图模式选择窗口或提醒窗口；
3. 检查 `fit_window_to_content()` 的最大屏幕比例；
4. 不要删除固定底部区域或把娱乐封锁重新放回滚动主体。

### 娱乐封锁失败

检查：

- `D:\Cold Turkey\Cold Turkey Blocker.exe` 是否存在；
- Cold Turkey GUI 中是否存在完全同名的 `常刷网站` 和 `bilibili` block；
- `config.json` 中的路径和 block 名是否正确；
- 控制页是否显示“开启失败或不完整”。

## 13. 设计边界

- 实时检测和提醒必须在 Windows 本地完成，不经过树莓派网络链路。
- 使用确定性摄像头占用信号，不让 AI 判断是否正在通话。
- 腾讯会议只靠精确可执行文件排除，不使用模糊的“腾讯”关键词。
- 娱乐封锁必须由用户在模式选择窗口勾选，或在控制页手动确认。
- 不把安静、没有鼠标键盘操作或没有说话解释为走神。
- 不读取或记录关系对象、聊天内容和音视频内容。
- 本工具不替代 [[本地Cold Turkey自动开启模块]] 的半小时行为介入链路，两者只复用 Cold Turkey 安装和既有 block。
