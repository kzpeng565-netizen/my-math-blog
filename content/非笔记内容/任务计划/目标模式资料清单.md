# 目标模式资料清单

此清单是 Goal Agent 读取学习资料的授权边界。只有同时满足以下条件的条目才会被 Windows 导出器处理：

1. 方框由我改为 `[x]`；
2. 条目中填写一个位于当前 Vault 内的 `[[相对路径]]`；
3. 文件类型为 PDF、Markdown 或纯文本。

未勾选、路径缺失、Vault 外路径或其他文件类型都不会导出。PDF 按页提取，Markdown/文本按小段提取；每份导出都记录来源路径、修改时间和 SHA-256。MathInk 笔迹载荷与内嵌 base64 图片不会进入导出文本。

> [!warning] 使用边界
> 请只授权当前目标判断确实需要的资料。取消勾选会阻止后续重新提取；已同步的旧压缩副本仍需通过运维清理流程删除，不在导出时自动破坏性清理。
