> 每周三天集中家教，三天深度学数学，一天复盘休息；遍历论按“读书—笔记—博客—导师问题”推进。

**暑假总目标**  
你最合理的目标是：

1. 家教固定为每周5节，共7.5小时授课；备课约7.5小时，相关总占用约15小时。
2. 遍历论前四章完成一轮。
3. 写出3篇短博客。
4. 和导师进行2–3次有内容的线上交流。

不要把目标定成“看完整本书”。你的目标是把前四章真正吃下来。

**六周学习主线**

第1周：第1章快速浏览 + 第2.1–2.2  
重点：遍历论研究什么、measure-preserving transformation、recurrence、Poincaré recurrence theorem。  
产出：一页路线图 + 第一次笔记。

第2周：第2.3–2.5  
重点：ergodicity、invariant set/function、Koopman operator、mean ergodic theorem。  
产出：第一篇博客初稿：《遍历性 ergodicity：动力系统中“不可分解”的意思》。

第3周：第2.6–2.8  
重点：Birkhoff theorem、pointwise average、weak mixing、strong mixing。  
产出：第二篇博客初稿：《Birkhoff 遍历定理：时间平均为什么能等于空间平均？》。

第4周：第3章  
重点：continued fractions、Gauss map、Gauss measure、badly approximable numbers。  
产出：第三篇博客：《从连分数到 Gauss map》。

第5周：第4.1–4.3  
重点：invariant measure existence、ergodic decomposition、unique ergodicity。  
产出：导师沟通问题 + 一页读书报告框架。

第6周：第4.4 + 总复盘  
重点：equidistribution、generic point、unique ergodicity 与等分布的关系。  
产出：整理前四章笔记，准备发给导师的1–2页读书报告。

**每天学习模板**

每次学习不要只是“看书”。按这个流程：

1. 先读英文原文。
2. 遇到卡点，用AI解释证明逻辑，不要整页翻译。
3. 用中文写笔记，英文术语保留。
4. 每节结束回答六个问题：

```
这一节研究什么？
核心定义是什么？
核心定理是什么？
证明关键想法是什么？
典型例子是什么？
它和前后章节有什么关系？
```
